## 情報の出順 `[確定]`

地獄側の真の目的は最終局面まで出さない。「AI運用試験」は庁の説明ではなく、主人公の仮説である。

| 時点 | 主人公が知っていること | 出し方 |
| --- | --- | --- |
| 序盤 | 地獄庁の仕事で、獄卒を連れて塔を登っている | 独白・業務 |
| 中盤の少し前 | 自分の脳は現世に残り、AIとして動いている | 正体の手がかりとなるセリフ可 |
| 中盤 | **仮説**: この登塔は、AIで獄卒を運用できるかの試験 | **主人公の独白だけ**。地の文・職員のセリフでは事実として言わない |
| 最終局面 | 仮説は目的を誤っていた。詳細は [結末_閻魔.md](結末_閻魔.md) | 閻魔（名称は仮）が明かす |

仮説の材料になる観察は本当である。

- 代理脳だけでは、煽りの残りを処理しきれない
- 主人公がいないと、割った亡者はまた亡者に戻る
- 庁は理由を説明しない

間違っているのは「試験だから登らされている」という目的だけ。

## 地獄と塔 `[確定]`

地獄の本業は、罪のある魂を裁いて償わせること。プレイヤーが見るのは塔と、修復屋などの職員だけ。受刑区そのものは出さない。

| 層 | 役割 | 画面 |
| --- | --- | --- |
| 仕分け（閻魔庁） | 死後の判決。自殺は意図の審査が要り、地獄行はすぐ確定しない | 最終局面以外は出さない |
| 塔 | 判決できない同一案件の滞留場所 | 探索する場所 |
| 地獄（狭義） | 受刑区 | 見せない |

### 塔にあふれる亡者

塔の亡者は、扇動による同一案件の自殺者である。

1. 主人公の脳を組み込んだAIが、死を煽り、大量の自殺を起こした。
2. 一件ごとに「どこまで本人の意志か」を調べる列が溢れ、仕分けが止まった。
3. 地獄庁は、この案件の魂だけを塔へ移した。混ざったまま裁くと、扇動された者まで地獄行きになり、煽りの残りは被害者の中に隠れる。
4. 移した時点では魂だった。滞留が長く、死を煽った意志が殻になって亡者になった。庁が亡者に変えたのではない。
5. 未決の魂を砕く権限はない。砕けば本人ごと消え、判決を捨てることになる。

扇動された自殺は、本人だけの罪ではない。重い業は煽った側にあり、本人の意志は審査が終わるまで保留である。

八大地獄は塔そのものではない。使うなら階層帯の通称だけとし、罪目の対応表は作らない。

### 主人公が任務にあてられた理由

殻を割ると魂は還るが、煽りの残りは消えない。その場に作り主がいなければ魂へ再付着し、また亡者になる。

主人公の脳は現世に生きている。この扇動を起こした意志はその脳にある。割れる瞬間に主人公が立ち会い、残りを引き取る。引き取った分だけ、魂は本人の意志だけになり、仕分けへ戻せる。

「業が壊した瞬間に飛んで戻る」は経典の手続きではない。この作品の規則である。塔の汚染は業一般ではなく、この一件の煽りの残りと呼ぶ。

## 獄卒と代理脳 `[確定]`

獄卒 ＝ 魂＋再現肉体＋代理脳。初期の三人も、救出で増える者も、この型である。

| 項目 | 内容 |
| --- | --- |
| 狂気 | 代理脳が処理しきれない負荷。上限は代理脳の容量 |
| 装置 | 全員で共有。留守番も含め、全滅で記憶と信頼が消える |
| 帰還 | エレベーターで帰れば消えない |
| ジャックポット | 主人公が三人の狂気を引き取り、撃ち出す |
| 上限低下 | 一気に抜くと装置が傷む |
| 非開示 | 三人は代理脳・フォーマット・再利用を知らない。知ると士気が落ちるため、庁が教えない。主人公は知っているが、教えない |
| インストール | 獄卒化のとき意識と価値観を入れる。体の補修に違和感を持たない |

刻印（スキル）は探索パーティの代理脳に刻まれる。全滅のフォーマットで消える。塔片・レリックも失う。リールは主人公の脳に紐づくため残る。

## リール `[確定]`

悪魔のスロットではない。繰り返した探索で、主人公の脳が道を選べるようになったもの。役名は「〜の記憶」（仮）。例: 戦戦宝 → 血路の記憶。

三人は全滅のたびに忘れ、主人公だけが覚えている。この差が切なさの軸である。

## 新キャラの追加 `[確定]`

1. 進行に応じ依頼が発生する。
2. 指定階層に、救出対象の魂がいる。基本は「善人」。獄卒適正は稀。
3. 依頼受領時に、生前のプロフィールを読める。
4. 現場では、同一の魂が亡者化している。戦闘で殻を割り、主人公が煽りの残りを引き取る。
5. 魂は修復屋が回収し、肉体を再現し、代理脳を載せて獄卒にする。本人は戦闘も欠損の意味も知らない。
6. 初回の救出は善人で、キメラにしない。キメラはそれ以降。

「善人」は道徳の褒賞ではない。煽りを除けば、地獄行きが確定しない魂の区分である。加入は感謝ではなく、配属として描く。

### キメラ

対象は救出キャラのみ。生前に失った手足は再現できず、修復屋が別生物のパーツで補う。見た目だけの差分とし、性能は変えない。スキル名でパーツを匂わせる。本人はインストール済みのため、違和感を持たない。
