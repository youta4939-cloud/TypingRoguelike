# 作業指示書：エレベーター帰還と全滅のルール変更

対象リポジトリ：youta4939-cloud/TypingRoguelike（Unity 6000.3.25f1）
作成日：2026-10-12

## 目的
エレベーター帰還と全滅（HP0・発狂・放棄）の扱いを、2026-10-11/12 の決定に合わせる。
- 帰還では何も失わない。通貨は拠点に貯金する。
- 全滅すると、その探索で持っていたものを失う。
- 死亡や放棄で魔石の精算報酬は出さない。

## 範囲外（今回は触らない）
- エレベーターを固定の数階に置く変更（決定#3）。`_elevatorFloor = 1 + PositiveModulo(...)` と `DungeonMapGenerator.Generate` の配置ロジックはそのまま残す。
- 代理脳（外部装置）の強化と、通貨による狂気上限の強化。
- 経験（EXP）と、主人公の強化。
- ジャックポットごとの上限低下（装置の傷み）。
- 40階化。`towerFloors = 15` のまま。
- 戦闘、タイピング、UIの見た目（文言の修正は除く）。

## 前提（決定事項）
1. **全滅（HP0・発狂・放棄）**
   - 失うもの：装備スキル（刻印）、レリック、持っている通貨（塔片）。
   - ダンジョンは作り直し、マップと踏破状態もリセットする。
   - 解放済みのエレベーター階は残る。
   - 3人の記憶リセットはシナリオだけの話で、コードでは扱わない。
2. **エレベーター帰還**
   - 何も失わない。通貨は拠点に貯金する。
   - マップと踏破状態、刻印、レリックはそのまま残る。
   - 再出発は、1階か解放済みのエレベーター階のどれかを選べる。どちらでも装備を持ったまま再開する。
   - 廃止するもの：レリックを倉庫へ移す処理。「解放済みエレベーター階から始めると初期状態の新しい探索になる」ルール。
4. **報酬と放棄**
   - 死亡・放棄では魔石の精算（`15+マス×8`、`40+マス×10`）を出さない。
   - 放棄は全滅と同じ処理にする。

## セーブデータ移行
注意：今のコードの `MetaProgressData.version` は **2**。依頼文では「3→4」だったが、実際は **2→3** になる。

`Normalize` の中に `if (data.version < 3)` の処理を足す。
1. 新フィールド `bankedCoins`（仮）を追加する。既存のセーブでは0から始める。
2. 中断中の探索がある（`towerRunActive`）セーブ：
   - `towerRunCoins` はそのまま残す（再開時に持っている塔片として戻る）。
   - 倉庫にある `warehouseRelicIds` は、そのまま残す。探索への戻し方は未決事項3。
3. `version = 3` にする。
4. 魔石 `arcaneShards` は消さない。

## 未決事項（トダさん判断）
1. **通貨を1本にするか。** 今は塔片（探索中）と魔石（拠点）の2種類。
   - 案：貯金する通貨は塔片とし、名前は後で決める。今回は `bankedCoins` を新しく作り、魔石のフィールドは残す。
   - 別案：貯金を魔石に変換し、魔石に統一する。
2. **踏破報酬を残すか。** 最終階クリア時の `120+マス×15` の魔石。
3. **拠点レリック枠と倉庫の UI をどうするか。**
   - 案：倉庫は廃止し、コードは最小限の経路だけ残す。今は新しく入らないようにするだけ。
   - 既存の倉庫にあるレリックと、店・開発（魔石・素材で買う）をどうするかも決める必要がある。
4. **セーブ移行の扱い。** 旧セーブの倉庫レリックや魔石残高を変換するか、そのまま捨て置くか（開発中なら、セーブを消す前提でもよいか）。
5. **素材の扱い。** 帰還時に拠点へ貯めるか、探索の中に残すか。全滅で失うか。
6. **拠点のボタン構成。** 「中断した探索へ戻る（N階）」を残すか。「1階から」と「エレベーター階から」だけにするか。
