## 1. いまのゲーム

3人パーティで塔を登るタイピングローグライク。

- マップでマスを選び、危険地帯ではタイピング戦闘に入る。
- 単語を打ち切るとオーブが溜まり、末尾が揃った刻印（スキル）が発動する。
- 打ち切った文字数だけ **狂気** が増える。限界に達すると発狂で探索終了。
- 単語ごとに **ジャックポット** を1回抽選する。当たると、その時点の狂気をダメージに変えて狂気を0に戻す。
- 刻印は宝箱と行商人で入手し、同じ刻印はレベルアップする。
- レリックは行商人（高額・約半数の店）か、出来事マス（稀）でのみ手に入る。装備は3枠。

パーティは固定3人。HP は共有。通貨は探索中の **塔片** と、拠点の **魔石**。

## 2. 探索

### 2.1 塔の形

| 項目 | 現行 |
| --- | --- |
| 階層数 | 15（定義上の上限は 99。本番想定の余地） |
| 1階層 | スタート1 ＋ 3列×6段 ＋ 階層ボス1 |
| ルート | 隣の列へ進む。約42%で二股。行き止まりのマスには手前から線が補われる |
| 未踏 | `?`。踏んだマスは種類が見える |
| 同一探索の再訪 | 探索シード＋階層番号で同じレイアウト |
| エレベーター | 探索ごとに1階層だけ自然配置。解放済みの階から新規探索を始めるとき、その階にも強制配置 |

5階層ごとに敵が一段強くなる。速度は変わらない。

| 帯 | 階層 | 敵HP | 敵の攻撃 |
| --- | --- | --- | --- |
| 0 | 1–5 | ×1.00 | ×1.00 |
| 1 | 6–10 | ×1.45 | ×1.30 |
| 2 | 11–15 | ×1.90 | ×1.60 |

帯の計算は `(階層 - 1) / 5`。帯0は倍率を掛けない。帯1以上は HP に `1 + 帯×0.45`、攻撃に `1 + 帯×0.30` を掛ける。

### 2.2 マスの出方

スタートとボス以外を抽選する。最終段（ボスの直前）は宝がやや多い。

道中（100面の出目）:

| 出目 | マス |
| --- | --- |
| 0–25 | 通常 |
| 26–53 | 危険 |
| 54–67 | 行商人 |
| 68–75 | 出来事 |
| 76–99 | 宝箱 |

最終段:

| 出目 | マス |
| --- | --- |
| 0–21 | 通常 |
| 22–47 | 危険 |
| 48–61 | 行商人 |
| 62–69 | 出来事 |
| 70–99 | 宝箱 |

その後、休息を1〜2個に揃える。多い分は通常へ戻し、足りなければ通常から休息へ変える。  
エレベーター階では、中間の段の1マスをエレベーターに差し替える。

危険マスの遭遇率は 10% 刻み（10〜80）。深い段ほど高くなりやすい。  
危険のうち強敵になる割合は、シード・階層・マスIDから決まる 38%。危険察知があると、入る前に「強敵の気配」か「通常程度」と出る。

### 2.3 マスに入ったとき

**通常**  
ログ「静かな通路を進んだ。」だけ。報酬なし。

**危険**  
表示された遭遇率から、レリックと探索パッシブの軽減を引いた実効率で判定する。  
出会わなければ報酬なしで踏破。出会えば戦闘。勝利報酬は塔片のみ（通常 8、強敵 15）。刻印は出ない。

**休息**  
最大HPの 15% 回復。

**宝箱**  
塔片 +10。その階の素材を 1〜2 個。刻印を1枚選ぶか、塔片だけ持って戻る。  
レリックは出ない（確率 0）。

**行商人**（このマスを開いているあいだ、何度でも買える）

| 品 | 価格 | 効果 |
| --- | --- | --- |
| 体力回復 | 10 塔片 | 最大HPの 12% |
| 刻印 | 22 塔片 | 3択から1枚 |
| レリック | 60 塔片 | 店の約半数に1個。シードとマスで固定。買うと再表示しない |

店を開き直しても、レリックの有無と中身は振り直されない。

**出来事**  
無料のレリックを1個提示する。拾うか、見送る。見送るとそのマスは踏破され、同じ遺物は戻らない。  
カタログが空なら静かな通路扱いにする。

**エレベーター**  
踏むとその階がメタで解放される。  
「さらに進む」か「拠点へ帰還」。帰還しても探索は終わらない。装備中の刻印、塔片、踏破、狂気、ジャックポットの蓄積は残る。レリックと素材は拠点倉庫へ移り、探索側からは空になる。倉庫へ移したレリックは、同じ探索に戻しても再装備されない。

**ボス**  
撃破で次の階層へ。15階層のボス撃破で塔踏破（探索成功）。

### 2.4 探索の終わり方

| 終わり方 | 刻印 | レリック | マップ | 魔石 |
| --- | --- | --- | --- | --- |
| エレベーター帰還 | 残る。同じ探索へ戻れる | 倉庫へ移る。塔には戻らない | 維持 | この時点では精算しない |
| 死亡（HP0 または発狂） | 初期スキルだけに戻る | 探索中の所持は失う。倉庫は残る | 再生成。踏破リセット | 失敗報酬 |
| 放棄 | 初期スキルに戻す | 探索側を捨てる | 踏破を消す | 失敗報酬 |
| 15階層踏破 | 探索終了 | 探索終了 | 終了 | 踏破報酬 |

魔石の目安: 踏破 `120 + 踏破マス×15`、撤退精算 `40 + 踏破マス×10`、失敗 `15 + 踏破マス×8`。  
エレベーター帰還そのものは精算しない。死亡・放棄・踏破のときに入る。

拠点から「解放済みエレベーター階で新規探索」を始めると、別の新しい探索になる。刻印は初期のみ、HP は全快、その階のエレベーター前から始まる。倉庫のレリックは持っていかない。

## 3. 戦闘

### 3.1 操作

- `a`–`z` で単語を打つ。
- 正解で1文字進む。ミスは音だけ。ダメージも狂気も抽選も起きない。
- 単語を1つ打ち切ると、オーブを1つ積み、狂気が増え、ジャックポットを1回抽選する。
- `Enter` でリロール（戦闘あたり 3 回）。単語が引き直される。
- `Space` で一時停止。

共有HPの初期値は 120（定義 100 の 1.2 倍）。戦闘をまたいで残る。

### 3.2 単語ダメージと敵

単語クリアのダメージは、パーティ攻撃の合計。いまの3人なら **15**。  
レリックの与ダメージ%は、この単語ダメージと刻印ダメージに掛かる。ジャックポットには掛からない。

被ダメージは `敵の攻撃 − パーティ防御軽減`。最低 1。いまの3人の軽減は 6。

敵の基礎値（階層倍率・戦闘種別の倍率を掛ける前）:

| 敵 | HP | 攻撃 | 攻撃速度 | 狂暴化 |
| --- | --- | --- | --- | --- |
| 魔物（危険の通常） | 260 | 18 | 0.32 | HP 45% 以下で 0.48 |
| 強敵 | 380 | 22 | 0.38 | HP 50% 以下で 0.58 |
| ボス | 1000 | 25 | 0.35 | HP 50% 以下で 0.55 |

戦闘種別でさらに掛かる倍率（そのあと階層の帯）:

| 種別 | HP | 攻撃 | 速度 | ジャックポット威力 |
| --- | --- | --- | --- | --- |
| 危険の通常 | ×0.72 | ×0.62 | ×0.88 | ×2.0 |
| 強敵 | ×0.612 | ×0.744 | ×0.88 | ×2.0 |
| ボス | ×0.90 | ×0.68 | ×0.88 | ×2.5 |

例: 1–5階層の魔物は HP 約 187、攻撃 約 11.2。被ダメは軽減 6 を引いて約 5。  
11–15階層のボスは HP 約 1710（1000×0.90×1.90）、攻撃 約 27.2（25×0.68×1.60）。

攻撃ゲージが尽きると敵が殴る。ゲージの速度は階層では変わらない。  
HP が狂暴化ラインを割ると速度が上がる。

### 3.3 刻印の発動

打ち切った単語の色がオーブになる。色は赤・青・黄・紫・緑。  
装備中の刻印は、オーブ列の **末尾** がパターンと一致すると発動する。複数が同時に揃えば同時発動。  
発動した刻印は、別の刻印が発動するまでクールダウンする。

刻印の効果はダメージ、回復、敵の攻撃低下、リロール回復。詳細は §5。

### 3.4 戦闘開始時の敵停止

レリック「静止の鐘」があると、カウントダウン（GO）のあと、敵の攻撃ゲージを指定秒数止める。いまは 10 秒。複数あれば秒数は加算。止まっているあいだゲージは満タンの水色。動き出すとログが出る。

## 4. 狂気とジャックポット

この節の式は確定。調整しない前提。

### 4.1 狂気

| 項目 | 値 |
| --- | --- |
| 開始 | 0 |
| 上限の基本 | 1000 |
| 上限の増え方 | 装備レリックの加算だけ。いまは「溢れる盃」で +200（上限 1200） |
| 増え方 | 単語を打ち切った文字数。ミスでは増えない |
| 段階表示 | 30%以下 平静、60%以下 警戒、90%以下 危険、それ以上 臨界 |
| 発狂 | 単語完了で上限に達した瞬間。ジャックポットの抽選より先。GAME OVER |

上限をレリックで下げたとき、現在値が新しい上限を超えていれば上限まで切り下げる。その瞬間には発狂しない。次の単語で上限に触れると発狂する。

上限は「1000 ＋ いま装備している加算」で計算し直す。セーブに載った上限へさらに足さない。

マップの出来事から狂気を増減する入口（`ApplyMadnessDeltaFromEvent`）はある。いまのマスはまだ呼んでいない。増減してもジャックポットの蓄積率は変わらない。

### 4.2 抽選

単語を1つ打ち切るたびに1回。戦闘ごとに1回ではない。

```
当選率 = min(99%, 蓄積 + 運ボーナス + その他ボーナス + 条件付きレリック)
```

| 項 | 値 |
| --- | --- |
| 基礎当選率 | 0 |
| 蓄積 | 外れたとき、打ち切った文字数 × 0.0025%（内部値 0.000025） |
| 蓄積の上限 | 10% |
| 最終上限 | 99% |
| 運 | パーティ運 × 0.0005。いまの3人（運12）で 1語あたり +0.6% |
| レリック「臨界の賽」 | 狂気が 900 以上のとき、その抽選にだけ +10%。蓄積には書き込まない |

当たったあとは蓄積を 0 に戻す。外れた分の蓄積は戦闘をまたいで残る。  
表示の「次」がその語の実際の抽選。「蓄積」は持ち越し分だけ。

例: 蓄積 2.00%、運 0.60%、賽が有効なら  
`次 12.60% ＝ 蓄積 2.00% ＋ 運 0.60% ＋ 賽 10%`  
900 未満なら `賽は狂気900未満（今 N）`。

1戦闘で単語をたくさん打つと、1語の確率が小さくても「どこかで1回は出る」体感は高くなる。20語を各 2% で打つと、少なくとも1回当たる確率は約 33%。12% 前後だとほぼ毎戦闘に近くなる。

### 4.3 ダメージ

当たった語の狂気を足したあと、リセットの前に計算する。

```
威力 = round(現在の狂気 × 戦闘倍率)
```

戦闘倍率は通常・強敵が 2.0、ボスが 2.5。  
「臨界の賽」が条件を満たしているときは、その威力に 0.7 を掛ける（-30%）。

単語ダメージ、レリックの与ダメージ%、刻印ダメージはジャックポットに含まれない。  
当たると狂気は 0。蓄積も 0。演出は白い閃光、ブラックアウト、3人のカットイン、JACKPOT 連撃。

## 5. パーティと刻印

### 5.1 3人

ステータスは探索中固定。戦闘では合計して使う。

| 名前 | 表示役 | 攻撃 | 防御 | 運 | 初期刻印 | 探索パッシブ |
| --- | --- | --- | --- | --- | --- | --- |
| アリス | アタッカー | 7 | 3 | 2 | 二連斬 | 慎重。危険の遭遇率 −5% |
| エレン | ヒーラー | 3 | 6 | 2 | プチヒール | 先導。次に進めるマスの種類が見える |
| ルナ | メイジ | 5 | 3 | 8 | ウォータ | 危険察知。見えている危険マスが強敵かどうか分かる |

合計: 攻撃 15、防御 12、運 12。  
単語ダメージ `15 × 1 = 15`。被ダメ軽減 `12 × 0.5 = 6`。運の抽選加算 `12 × 0.0005 = +0.6% / 語`。

探索パッシブはキャラ固有。同じ種類が複数いても1人分だけ有効。  
実装済みの種類は次のとおり。いまパーティにいるのは上の3つ。

| 種類 | 効果 |
| --- | --- |
| 慎重 | 危険の遭遇率を下げる |
| 先導 | 次に進めるマスを開示 |
| 危険察知 | 危険が強敵か事前に分かる |
| 宝探し | 現在地から2ホップ以内の宝箱を開示 |
| エレベーター感知 | その階のエレベーターが見える |

表示役（アタッカー / ヒーラー / メイジ）はラベルだけ。装備制限には使っていない。刻印は `characterName` が一致するキャラにしか付かない。

### 5.2 装備枠

各キャラは初期枠1 ＋ 入手枠2。初期枠は入れ替え不可、レベルも上がらない。  
スキル用のバックパックはない。塔の途中でデッキを開けて入れ替えることもできない。入れ替えは、宝箱か行商人で新しい刻印を得たときだけ。

入手時:

1. 同じ刻印をすでに持っていて Lv.3 未満なら、その場でレベルアップ。
2. Lv.3 ならそれ以上は入らない。
3. 空き枠があれば自動で入る（Lv.1）。
4. 2枠とも埋まっていれば、どちらかと入れ替える。キャンセルするとその刻印は手に入らない。
5. 該当キャラがいない刻印は装備できない。

報酬の3択から、すでに Lv.3 の刻印は除外する。初期刻印（id 0, 3, 6）は報酬に出ない。

| 低下の秒数 | +25% / レベル |

## 6. レリック

### 6.1 ルール

- 入手はマップだけ。行商人（60 塔片、店の約 50%）か、出来事（無料、マス抽選の約 8%）。
- 装備 3 枠。新しい入手にバックパックは使わない。
- 空きがあれば入る。3 枠いっぱいなら、どれかと入れ替えるか断る。外したレリックはその探索では失う。
- 宝箱からは出ない。拠点の店では買えない。開発もいまは動かない。
- 拠点倉庫に入ったレリックは、次の探索にも同じ探索の再開にも持っていかない。
- 効果は装備中だけ。同種は加算（確率は足す、威力倍率は掛ける、停止秒は足す、狂気上限は足す）。条件の閾値は、0 以外で一番低いもの。
- 単独装備（`exclusiveEquip`）が1つでもあると、それ以外のレリックの効果は無効。単独を取るときは他をすべて外す。

「塔の瞳」の全開示は表示だけ。踏破情報には書き込まない。外すと、まだ踏んでいないマスは再び `?` になる。

## 7. 拠点

エレベーター帰還・死亡・放棄・踏破のあと、および起動時に探索が無いときに出る。

できること:

- 進行中の探索があれば、そこへ戻る（刻印・塔片・マップ・狂気は帰還時点のまま。レリックは倉庫に預けたあとなので塔側は空）。
- 解放済みエレベーター階から、新しい探索をその階で始める。
- レリック倉庫の閲覧。画面上の装備操作は残るが、塔には反映されない。
- 魔石で素材パックを買う。

できないこと:

- 刻印の編集。
- レリックの購入・開発。
- 倉庫レリックの塔への持ち込み。

## 9. 今後

ここから下は未実装。実装済みの節のルールとは別。

### 9.1 方針として置いてあるもの

**役職（未実装・名前は未確定）**  
刻印をキャラ固定から役職へ広げる案。

- 役は3つ ＋ 誰でも装備できる Natural。
- 案: アタッカー / ヒーラー / トリックスター。Natural の表示は「汎用」。メイジという呼び方は役の名前には使わない方向。
- 初期刻印はキャラ固有のまま。
- 同じ役、または汎用の刻印は、誰に付けるか選ぶ。すでに持っている人がいればレベルアップ。
- 名前が確定するまでコードには入れない。いまの装備はキャラ名一致のまま。

**狂気を動かす出来事とレリック**  
1000 という上限は、そのまま張力として残す。  
出来事の選択肢やレリックで、現在値と上限を上げ下げできるようにする。上限 +200 の盃はその第一弾。  
現在値を直接いじるレリックと、狂気の増減がある出来事はまだ無い。呼び出し口だけある。  
出来事で狂気が変わっても、ジャックポットの蓄積率は変えない。

**刻印のスプレッドシート取り込み**  
レリックは CSV 取り込み済み。刻印は生成コードの表が元。CSV が用意されたら、同じ形で取り込めるようにする。表が来る前には作らない。

**カードイラスト**  
枠・名札・効果札は入っている。絵は No Image。本画像が来たら同じ位置に差し替える。

**塔の長さ**  
データ上のコメントは本番 99 階層。遊べるのは 15。99 にするときは、帯の伸ばし方とエレベーターの置き方を別に決める。

**拠点のレリック経済**  
購入と開発の項目（魔石価格・素材コスト）は id 1〜6 に残っている。いまのループでは使わない。塔の中だけで回す、が現行方針。拠点から持ち込む形に戻すなら、そのときにルールを書き直す。

### 9.2 保留

- ジャックポットの式（0.0025% / 字、蓄積上限 10%、最終 99%、威力は狂気×倍率）。変えない。
- マップのルート線の見え方。気になる点として残っている。仕様変更としては未決定。

### 9.3 まだ決めていないこと
