更新: 2026-11-23（塔片・帰還の棚卸しを反映）

このファイルがシステムの正本。数値やルールが他の文書と違うときは、こちらを優先する。  
物語は [`Scenario/シナリオ.md`](Scenario/シナリオ.md)。そこにある「リールは全滅でも残る」は、システムの決定でもある。

読み方:

- **実装済み** … いまのコードがこう動く
- **決定** … 方針は決まっている。コードはまだ、または一部だけ
- **課題** … いまの数値や効果は仮。あとで変える
- **廃止** … もう使わない。古い文書に残っていても従わない
- **未決** … まだ決めていない

## 1. このゲーム

3人パーティで塔を登るタイピングローグライク。

狙いは、リソース管理が大事で、押し引きに緊張があり、次のランへ繋がること。軸は狂気。危なくなったらエレベーターで引き返す。ぬるくしない。完全な運ゲーにもしない。

プロトタイプの名前はアリス（攻撃型）、ルナ（バランス型）、エレン（支援型）。シナリオ上の本名は未定。

## 3. 1層の進み方

実装済み。

出発前にリール盤面を組む。盤面は 3列×6行。パーツは `Resources/Data/ReelParts.json`。  
各列から等確率で 1 マスを引く。道は 3 マス。4マス目は層番号で固定。

| 条件 | 4マス目 |
| --- | --- |
| 5 の倍数層 | ボス（エレベーターと重なってもボス） |
| 3 の倍数層 | エレベーター |
| それ以外 | 中ボス |

各列に戦闘が 2 マス以上ないと出発できない（`Resources/Data/ReelBoard.json`）。  
同じランの種・層・盤面なら、引くマスは同じ。再開しても変わらない。  
塔は 15 層。データの上限は 99。15 を超える伸ばし方は未決。

意見は、道の途中では出ない。リールの出来事（E）を引いたときだけ出る。詳細は第 9 節。

役（`Resources/Data/Yaku.json`）。効果は仮で、あとで変える課題である。

| 役 | 効果 |
| --- | --- |
| 戦闘×3 | その層の戦闘は、刻印の選択肢 +1 |
| 回復×3 | 4マス目の前に HP 20% 回復 |
| 宝×3 | その層で得る塔片 +50% |
| 3つとも違う | 塔片 +20 |
| 罠が含まれる | 不成立。罠の効果だけ |

## 4. マス

種類は実装済み。記号は B 戦闘、R 休息、S 行商人、T 宝箱、E 出来事。それ以外は罠。  
この節の割合と値段は仮である。あとで変える課題にする。素材は出さない。

| マス | 中身 |
| --- | --- |
| 戦闘 | 必ず戦う。意見は出ない |
| 中ボス | 強敵。意見は出ない |
| ボス | 階層ボス。5層ごとに4マス目。意見は出ない |
| 休息 | 最大 HP の 20% 回復。意見は出ない |
| 宝箱 | 塔片と刻印。意見は出ない |
| 行商人 | 回復（10塔片、最大 HP の 12%）、刻印、店の約半数にレリック（60塔片）。意見は出ない |
| 出来事 | 選択肢が2つ。意見はここだけ。選んだ結果は1つ。詳細は第 9 節 |
| 罠 | 最大 HP の 10% を失う。意見は出ない |
| エレベーター | その層を解放し、拠点へ帰るか次の層へ進む。意見は出ない |

## 5. 戦闘

パーティ側の計算は実装済み。HP は 3 人で共有する。個人 HP にはしない。

| キャラ | 役割 | HP | 攻撃 | 防御 | 運 |
| --- | --- | --- | --- | --- | --- |
| アリス | 攻撃型 | 250 | 200 | 80 | 20 |
| ルナ | バランス型 | 350 | 120 | 120 | 80 |
| エレン | 支援型 | 400 | 80 | 200 | 20 |
| 合計 | | 1000 | 400 | 400 | 120 |

操作は a–z で打つ。ミスは音だけ。Enter でリロール（戦闘あたり 3 回）。Space で停止。

```
単語ダメージ = 攻撃合計 × 入力文字数 × 0.0075
```

端数は四捨五入、最低 1。初期パーティの 5 文字は 15。

```
被ダメージ = 敵の攻撃 × 400 / (防御合計 + 400)
```

端数は四捨五入、最低 1。初期防御 400 なら半分入る。

スキルダメージは、そのキャラの攻撃 × 割合 × レベル補正。割合が無いときの固定値はデータに残している。  
回復は固定値。レベル補正はダメージも回復も、Lv.1 が 1.0、1 レベルごとに +30%（Lv.2 は 1.3、Lv.3 は 1.6）。  
共有 HP を 120 から 1000 にしたので、回復は同じ割合になるよう引き上げてある。プチヒールは 83。

敵の行動、威力、HP、階層による伸びは未定。一覧はあとから提案する。  
被ダメージの式は、敵の攻撃値が決まったあとも使う。

## 6. 狂気とジャックポット

抽選の式は実装済み。

開始は 0。上限の基本は 1000。レリックを足しても 1200 で止まる。修復屋では上げない。  
増えるのは、単語を打ち切った文字数。ミスでは増えない。  
上限に達した単語完了で発狂する。抽選より先。  
表示は、30% 以下が平静、60% 以下が警戒、90% 以下が危険、それ以上が臨界。

抽選は単語を 1 つ打ち切るたび。見るのは、その時点の蓄積だけ。1 語目は 0%。  
運は当選率に直接足さない。蓄積の伸びだけを変える。

外れたとき:

```
増加 = 入力文字数 × 0.00075% × (運合計 / 120)
```

運は 220 で頭打ち。220 なら伸びは 220/120 倍。  
蓄積の上限は 10%。最終的な当選率の上限は 99%。  
当たると蓄積は 0。狂気も 0。

```
威力 = round(現在の狂気 × 戦闘倍率)
```

通常と強敵は 2、ボスは 2.5。  
レリック「臨界の賽」は、狂気 900 以上の抽選に +10%。その威力は ×0.7。与ダメージ % はジャックポットに掛からない。

廃止した旧式は、1 文字あたり 0.0025% の蓄積に、運を 1 語あたり直接足す計算。もう使わない。

装置の傷みは、ジャックポットで上限が下がる、というシナリオの決定。減る量は未決。コードは上限からペナルティを引く欄と、帰還で 0 に戻す処理だけがある。実際に減らす処理はまだ無い。

## 7. 刻印

枠の数は実装済み。初期スキルのレベルと入れ替えは決定で、コードは未追随。

各キャラの枠は 3 つ。初期枠 1 と入手枠 2。最大 Lv.3。  
同じ刻印を得たときは、空きがあってもレベルが上がる。初期刻印も同じ。  
枠が 3 つ埋まっているときだけ、外す対象に初期枠を含められる。空きがあるあいだは、初期枠は入れ替えない。  
Lv.3 はもう入らない。断ると手に入らない。  
初期刻印は報酬に出ない。  
オーブは赤・青・黄・紫・緑。装備中の刻印は、オーブ列の末尾が、そのスキルの並びと一致すると発動する。  
一覧の正はスキルアセット。スプレッドシートからの取り込みは未実装。

コードは、初期刻印をレベルアップせず、満杯でも初期枠を入れ替えられない。

## 8. レリック

装備のルールは実装済み。

レリックは装備 3 枠。効果は装備中だけ。拠点の倉庫から塔へは持っていかない。  
購入と開発の価格はデータに残っているが、いまのループでは使わない。  
一覧の正は `Assets/_Project/Docs/relics.csv`。バックパック枠を増やすレリックは旧定義。

狂気上限を上げるのはレリックだけ。合計は 1200 で止まる。  
運の上限 220 は残す。キャラ変更や上乗せが 220 を超えても、抽選の伸びは 220 として計算する。

修復屋は廃止した。コードの拠点には残っている。

## 9. 意見と信頼

決定。コードは、1〜3マス目に入る前に意見を出している。

意見が出るのは、リールの出来事（E）を引いたときだけ。戦闘、休息、行商人、罠、宝箱、ボス、エレベーター、中ボスでは出さない。

各出来事の選択肢は 2 つ。各選択肢には、性格ごとの意見発生率がある。抽選で、0 人から 3 人までが話す。  
プレイヤーは、誰が話したかにかかわらず、2 つのうちどちらかを選ぶ。選んだ結果は 1 つ。例は、強敵との戦闘、レリックの入手、スキルのレベルアップ。種類の一覧は未定。

信頼が動くのは、意見を言ったキャラだけ。

| 話した側 | 信頼 |
| --- | --- |
| プレイヤーが選んだ側 | 上がる。基本は +2。出来事によっては +3 |
| 逆の側 | 下がる。基本は −2。出来事によっては −3 |
| 意見を言わなかったキャラ | 動かない |

性格の表示名は、コード上は「勇敢／臆病／好奇心」。シナリオで仮に置いた三人（けだるげ、くそ真面目、ちびで生意気）にはまだ合わせていない。

信頼はキャラ個人の値で、5 ごとに主ステータスが +2 される。

| キャラ | 表示 | 5 ごとに上がるもの |
| --- | --- | --- |
| アリス | 攻撃型 | 攻撃 |
| エレン | 支援型 | 防御 |
| ルナ | バランス型 | 運 |

25、50、75、100 では、ステータス上昇ではないパッシブが付く。戦闘開始時に敵が 5 秒動かない、は例である。中身は未定。  
割合で攻撃が上がるパッシブと、その合計 20% の上限は廃止した。

全滅で信頼は消える。これはシナリオと一致している。

## 10. 帰還、全滅、経験値、依頼

### 10.1 帰還

装備・HP・狂気の扱いは実装済み（帰還で HP 満タン・狂気 0・装置の傷み解除）。

エレベーターで拠点へ帰る。

- 刻印、レリック、踏破は残る。次は 1 階か、解放済みのエレベーター階から、装備を持ったまま再開できる。
- **塔片**は、手持ちと別口座の「貯金」に分けない。塔内で得た枚数が、そのまま拠点でも所持として残る。拠点の代理脳強化なども、この塔片で払う。
- HP と狂気は両方とも全快にする。これが引き返す理由。**次の層へ進む**（帰還せずエレベーターで上がる）ときは、HP も狂気も持ったまま。
- 途中の帰還は禁止しない。

コードは、帰還時に塔片を `bankedCoins` へ移して手持ちを 0 にする処理がまだ残っている（正本と不一致）。

### 10.2 全滅

HP 0、発狂、放棄。失うものの扱いは実装済み。採点は未実装。

失うもの: そのランの刻印、レリック、**塔片（所持は 0）**、踏破。  
残るもの: 解放済みのエレベーター階、組んだリール盤面（シナリオどおり。コードは未追随）、代理脳など**塔片以外**の恒久強化。  
放棄は全滅と同じ。

死のペナルティは、そのランの採点にかける。すでに貯金した経験値、解放済みのビルド、到達済みの救出からは引かない。

シナリオではリールは主人公の脳に紐づくので、全滅でも残る。コードは盤面を空にする。正本は「残す」。直すまでは、プレイすると消える。

魔石は廃止した。コードは、最終層の踏破で魔石をまだ足している。

### 10.3 経験値

決定。未実装。

ゲームオーバーでも残る成長は、主人公の経験値。  
帰還したときに採点が入り、経験値になる。死んだときは、そのランの合計の 3 割から 5 割を残す。目安であり、正確な割合は未決。

使い道は二つ。

- 累計の到達でイベントが起きる（仲間の救出）。
- 貯めた経験値を消費してビルドする（リールのパーツ、パッシブ）。次のランですぐ感じる変化。

採点の目安。一層を普通に踏破したときを 100 とする。数値は未確定。深い階ほど伸びる。どの階で帰っても同じ点数にはしない。

| 項目 | 一層あたり |
| --- | --- |
| 入力文字数 | 40 |
| 雑魚の撃破 | 25 |
| 踏んだマス | 15 |
| ボス撃破 | 20 |

加点は、雑魚の撃破数、ボス撃破数、正しく入った文字数、踏んだマス数。  
減点は、タイピングミス数と死。ミス 1 回は、寄り道 1 つより軽くする。

### 10.4 依頼

決定。未実装。

最初の依頼は短い帰還。

- 最初は、どこかの層から一度帰還する。
- 次は、3 層まで登って帰還する、のような短い区間。
- 報酬は、そのランの採点に一層分を足す程度。

15 層を倒して最後に帰還したランには、ご祝儀を足してよい。目安は二層から三層分。一塔ぶんの経験値にはしない。15 層到達を最初の依頼にはしない。途中帰還を禁止する条件にもしない。

エレベーターが離れて置かれる場合、依頼が入口と帰還場所を指定する。例は「3 層から入って 12 層で帰還」。この階番号は例であり、塔をその階数に変える決定ではない。  
報酬は、その区間の採点をもう一度足すくらい。今日の依頼の階から入った方が、いちばん深い入口から入るより経験値が多くなるようにする。  
仲間の救出は一度きり。救助したあとも同じ階へ戻る理由は、階を指定した依頼の方。

## 11. 廃止

- 素材。塔片や経験値と役割が重なる。階ごとの収集品で下の階へ戻る理由は作らない。その理由は依頼が持つ。コードと拠点の店には残っている。
- 修復屋。狂気上限、最大 HP、休息時の狂気回復を拠点で買うこと。コードの拠点には残っている。
- 魔石。塔片以外の拠点通貨。コードは最終層の踏破でまだ足している。
- 塔片の「貯金」「口座」（`bankedCoins` 等）。塔片は一本の所持のみ。
- 3列×6段の分岐マップ、未踏の「?」、危険マスの遭遇率。リールの 3 マスと、固定の 4 マス目に置き換わった。
- 1〜3マス目の前に必ず意見が出るルール。信頼の +5、+15、−5 と、75 以上の追加減点。
- 信頼による割合の攻撃上昇と、その合計 20% の上限。
- 単語ダメージが文字数と無関係に、攻撃合計だけになる計算。
- 防御を固定値で引く計算。
- 運を 1 語の当選率へ直接足す計算。
- スキル用バックパック。戦闘中の装備変更。
- 倉庫のレリックを次の探索へ持ち込むこと。
- 解放済みエレベーター階から始めると、初期装備の別探索になるルール。装備を持ったまま再開する。
- 初期刻印は入れ替え不可で、レベルも上がらない、というルール。
