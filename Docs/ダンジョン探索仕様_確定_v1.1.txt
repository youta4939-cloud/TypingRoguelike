1. 目的（変更後の体験）
--------------------------------------------------------------------------------
・マス進行の中心を「確定イベント連打」から「情報・リスク・ルート判断」へ。
・Danger の遭遇率、踏破情報、エレベーター位置などを見ながら進む。
・RUN 内はスキルカードを現地調達。メタ成長は素材・レリック（拠点倉庫）中心。
・v1.0 のマス種整理（Normal / Danger / Treasure / Rest / Merchant / Elevator / Boss、
  Combat・Elite・Event 廃止）に従う。詳細は v1.0 を参照。


2. マス種と進入時の挙動
--------------------------------------------------------------------------------
【Normal】
  ・基本何も起こらない。
  ・表示は 1 行ログ程度（例:「静かな通路を進んだ。」）でマップに戻る。
  ・モーダルは最小 or ログのみ。

【Danger】
  ・マスに「敵遭遇率」を設定（表示例: 危 30%）。
  ・進入時に判定: 成功 → 戦闘、失敗 → 何も起こらない。
  ・戦闘しなかった場合: 報酬なし（塔片・カード・レリック一切なし）。
  ・短い 1 行ログでマップ復帰可。
  ・戦闘に入った場合の報酬は §4（塔片のみ。カードなし）。
  ※ v1.0 §5「危険度に応じた報酬」は、非遭遇報酬ではなく
    「戦闘勝利時の塔片量調整」に読み替える（未遭遇タダ得は作らない）。

【Treasure】
  ・確定報酬。§4 参照。

【Rest / Merchant / Elevator / Boss】
  ・v1.0 どおり。Boss 撃破で次階層へ。


3. エレベーター帰還 vs 死亡
--------------------------------------------------------------------------------
【エレベーターから拠点へ帰還】
  ・現在の RUN を終了しない（RunSeed・階マップ・踏破情報を維持）。
  ・スキルカード: RUN 内装備・バックパック含め全ロスト（図鑑へのカード確保は行わない）。
  ・レリック: RUN 上の装備 3 枠＋バックパック分を、メタ「レリック倉庫」へ強制保管。
  ・素材: RUN 内拾得分を、メタ「素材倉庫」へ強制保管。
  ・塔片: 同一 RUN 継続のため RUN ウォレットは維持（拠点店が別通貨なら将来分離可）。
  ・その後拠点 UI を表示（§5）。

【死亡】
  ・拠点へ強制送還。
  ・RunSeed を更新し、ダンジョンマップを再生成。
  ・踏破情報（revealed）をリセット（未探索 ? から）。
  ・RUN に持ち込んでいたレリック（装備・バックパック）はロスト。
  ・メタのレリック倉庫・素材倉庫・解放済みエレベーター階は維持。
  ・死亡後、解放済みエレベーター階から再入可能だが、その階のマップ配置・踏破は
    前 RUN のまま残らない（v1.0 §10–11）。


4. 塔片・カード・レリック経済（RUN 内）
--------------------------------------------------------------------------------
| 入手経路              | 塔片 | スキルカード | レリック      |
|-----------------------|------|--------------|---------------|
| Danger → 戦闘勝利     | ○    | ×            | ×             |
| Danger → 非遭遇       | ×    | ×            | ×             |
| Treasure              | ○主  | ○            | 極稀          |
| Merchant              | 消費 | ○（購入）    | ×（拠点中心） |
| Normal / Rest 等      | ×    | ×            | ×             |

  ・毎 RUN 開始: 各キャラは初期スキルのみ。カードは塔内で宝・商人のみ取得。
  ・刻印イベント（Event）マス・戦闘後カード 3 択は廃止方向。
  ・レリック: 探索時に持ち込めるパッシブ。死亡時は RUN 持ち込み分ロスト（§3）。


5. 拠点 UI（エレベーター帰還後・死亡後・初回）
--------------------------------------------------------------------------------
【エレベーター帰還後】
  ・必ず拠点 UI を表示。
  ・拠点で可能: レリック倉庫からの装備、店での購入、素材を使ったレリック開発。
  ・再侵入:
      A) 1 層から（初回・死亡後など）
      B) 解放済みエレベーター階を選択 → 同一 RUN のダンジョンマップ画面へ
         （帰還直後の主導線。マップ・踏破維持）

【帰還時の倉庫ルール（確定）】
  ・帰還確定時に CommitRunLootToMeta 相当の処理を 1 回実行。
  ・レリック・素材は RUN 内に未預けを残さない。再入時は倉庫＋拠点で選んだ装備 3 枠のみ。
  ・帰還モーダル例:「レリックと素材を拠点倉庫に預けた。カードは失われた。」

【死亡後】
  ・拠点 UI。1 層から or 解放済みエレベーター階から再スタート。


6. レリック装備ルール
--------------------------------------------------------------------------------
  ・装備枠: 3（パッシブ。探索・戦闘に効く想定）。
  ・取得時: 空き枠があれば自動装備。満杯ならバックパックへ。
  ・装備変更: ダンジョン内でも拠点でも可能。
  ・塔内取得〜次の帰還まで: RUN 上の 3 枠＋バックパックで保持。
  ・エレベーター帰還: 上記すべてレリック倉庫へ強制移動（§5）。
  ・同 RUN 再入: 拠点で装備し直してから出発（空き 3 枠から）。

  ・探索パッシブ（キャラ固有・パーティ在籍で有効）とレリックは別カテゴリ（v1.0 §7–8）。
    重複・スタックルールは v1.0 どおり（固有パッシブは非スタック設計）。


7. 踏破・マップ永続（RUN スコープ）
--------------------------------------------------------------------------------
  ・未踏マス: ?
  ・踏破後: 種類表示（Normal / 危 XX% / Treasure 等）。
  ・エレベーター帰還: マップレイアウト・踏破状態を次回の同 RUN 再入でも維持。
  ・死亡: マップ再生成＋踏破リセット。
  ・恒久: 解放したエレベーター階のみメタで維持（死亡後も利用可）。

  ・同一 RUN 中、同一階の再訪は RunSeed + FloorNumber により同一レイアウト（v1.0 §13）。


8. データモデル（実装指針）
--------------------------------------------------------------------------------
【メタ（MetaProgressData 拡張想定）】
  ・towerSeed（死亡時更新）
  ・revealedTowerNodeIds → 現 RUN の踏破として扱い、死亡でクリア、帰還で維持
  ・unlockedElevatorFloors（名称は実装に合わせる）
  ・素材倉庫（カウンタ or ID→数量）
  ・レリック倉庫（所持 ID リスト）
  ・arcaneShards 等（拠点通貨・店）
  ・unlockedSkillIds: キャラ開放等に流用可。カード図鑑確保は廃止方向

【RUN 中】
  ・塔片（RunCoins）
  ・スキルカード装備・バックパック（帰還で全消去）
  ・レリック装備 3＋バックパック（帰還で倉庫へ移動）
  ・素材拾得バッファ（帰還で倉庫へ移動）

【廃止・作り替え対象（現プロト）】
  ・ExtractRun による AddSkillsToArchive / 「カードを確保」UI
  ・Combat / Elite / Event マスと固定戦闘マス生成
  ・宝＝塔片のみ（カード・稀レリック未実装）
  ・死亡時の towerSeed / revealed リセット未実装
