# ロードマップ（販売まで）

更新: 2026-11-23  
詳細タスクは [`WBS.md`](WBS.md)。差分メモは [`SPEC_DRIFT.md`](SPEC_DRIFT.md)。

## ゴール

3人パーティのタイピングローグライクを、**15層を何度も回せる縦通し**から Steam 発売可能な体裁まで届ける。

## 並行トラック（同時進行）

| トラック | 主担当 | いまの焦点 |
| --- | --- | --- |
| **A. 正本とコード** | エージェント＋ユーザー判断 | M0：帰還・通貨・リールの確定を正本と実装へ反映 |
| **B. 縦通しの安定** | エージェント | M1：ソフトロック・セーブ再開・通貨の新ルール |
| **C. コンテンツ量産** | ユーザー（エージェントはデータ化支援） | 回復役③人目のイラスト・スキル12種、出来事50件 |
| **D. 成長・依頼** | エージェント（仕様確定後） | M3：経験値の消費先・依頼 |
| **E. 手触り・Steam** | 後半 | M4〜M5 |

**運用の方針:** ユーザーは①②③に集中してよい。エージェントはチャット指示時に A→B を進め、C が Unity に入るタイミングで WBS の **C.*** と **3.*** を接続する。
