# 進捗管理の進め方

更新: 2026-11-23

このフォルダが、販売までの **ロードマップ／WBS／仕様同期** の置き場。  
エージェントはユーザーからチャットで呼ばれたときに動く。常時監視はしない。

## 役割分担

| 誰 | やること |
| --- | --- |
| ユーザー | チャットで着手指示、仕様の最終判断、プレイ確認 |
| エージェント | コード照合、質問の整理、正本更新案、優先度更新、実装タスクの分割 |

古いメモ（`ゲーム仕様_現状と今後.md`、探索仕様の旧版など）は参考。衝突したら正本を優先し、正本を直す。

## 仕様の直し方

1. 領域を1つ選ぶ（例: 帰還、通貨、リール）
2. コードの実挙動を確認する
3. ユーザーに「いまの意図」を短く確認する
4. 正本を更新する（実装済み／決定／課題／廃止／未決）
5. WBS の該当項目を更新する

## チャットの使い方

- **進捗・仕様正本**用のチャットを新規に作る（この UI チャットとは分ける）
- 作業のたびに「WBS のどれから」か「棚卸しの続き」と指示する
- UI 方針・イラスト量産はテーマ別チャットのまま
