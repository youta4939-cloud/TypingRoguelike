# キャラクター拠点サンプル

character-hub.html をブラウザで開く。ゲーム本体・セーブの変更なし。

- 全画面の部屋とキャラクター、左側の横書きメニュー。
- ホバー／キーボードのフォーカスでメニューを強調し、想定ポーズの説明を表示。
- 施設選択で仮のパネル、塔選択で階段／エレベーターを表示。
- エレベーターは解放した層のみ数字と操作を有効化。行き先選択後「閉」で模擬移動。「開」でリセット。
- 素材は通常ポーズの一枚絵のみ。キャラのランダム表示・ポーズ切り替えは未実装。
- 本番素材は背景・キャラ・UIを分離。今回の画像に焼き込まれた文字は周辺のマスクで隠しているため、画面比率によって見切れ方が変わる。

画像: character-room-concept.png。組み込み image_gen で生成。
