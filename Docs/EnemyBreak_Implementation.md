# 敵HP・BREAK HUD

2026-11-15 実装。UI全体の刷新ではなく、敵HPとBREAK部分のみ置換。

- 敵名左の赤アクセント、名前幅だけの下線。強敵バッジなし。
- 現在HPは大きく、最大HPは48%サイズ。HP・BREAKのラベルに囲み枠なし。
- HPバーは30px高、滑らかな赤の陰影。HP下の区切り線なし。
- 盾は丸みのある上端と尖った下端。未消化は塗装色＋金属の縁、消化済みは暗いグレー。
- 同じ外形を5片に分割し、中心から破片が飛び出して落ちる0.48秒の演出。ポーズ中は進まない。
- UIはUnityの頂点メッシュで描画。参考画像の切り抜きや生成モック画像は実行時に使用しない。

## ルールと仮設定

`EnemyDefinition` の `breakEnabled` / `breakRequirements` / `breakDuration` / `breakDamageMultiplier` で敵別設定。
初期値は赤3・青3・黄3、4秒停止、敵への最終ダメージ1.5倍。秒数・倍率は調整用の仮値。

通常単語（色オーブを獲得する完成処理）が該当色の最も左の未消化盾を1つ消化する。順不同。
最後の盾を消化した語と、その語で自動発動するスキルにも倍率が適用される。
発狂判定が先なので、発狂した語では盾を消化しない。
Exの無色特殊攻撃は盾を消化せず、与ダメージ倍率は受ける。

ブレイク中は敵の通常攻撃・強攻撃タイマー、敵の新規状態異常付与を停止する。
既に受けた毒・伝播などの経過は進む。通常のポーズ・メニュー・カウントダウン・JP中はブレイク時計も止まる。
別要因の敵停止はブレイクで上書きせず、残り時間を保持する。
ブレイク中に次周の盾は消化できず、復帰すると同じ要求がすべて復元される。

プレハブ読み込み経路とコード生成経路の両方で新HUDを使用する。シーンや既存プレハブの保存変更は不要。

## 確認
