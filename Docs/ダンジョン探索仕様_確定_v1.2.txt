1. 目的（変更後の体験）
--------------------------------------------------------------------------------
・マス進行の中心を「確定イベント連打」から「情報・リスク・ルート判断」へ。
・Danger の遭遇率、踏破情報、エレベーター位置などを見ながら進む。
・RUN 内はスキルカードを現地調達（宝・商人）。メタ成長は素材・レリック（拠点倉庫）中心。
・v1.0 のマス種整理（Normal / Danger / Treasure / Rest / Merchant / Elevator / Boss、
  Combat・Elite・Event 廃止）に従う。詳細は v1.0 を参照。


2. マス種と進入時の挙動
--------------------------------------------------------------------------------
【Normal】
  ・基本何も起こらない。
  ・表示は 1 行ログ程度（例:「静かな通路を進んだ。」）でマップに戻る。
  ・モーダルは最小 or ログのみ。

【Danger】
  ・マスに「敵遭遇率」を設定（表示例: 危 30%）。
  ・進入時に判定: 成功 → 戦闘、失敗 → 何も起こらない。
  ・戦闘しなかった場合: 報酬なし（塔片・カード・レリック一切なし）。
  ・短い 1 行ログでマップ復帰可。
  ・戦闘に入った場合の報酬は §4（塔片のみ。カードなし）。
  ※ v1.0 §5 は「戦闘勝利時の塔片量調整」に読み替える。

【Treasure】
  ・確定報酬。§4 参照。

【Rest / Merchant / Elevator / Boss】
  ・v1.0 どおり。Boss 撃破で次階層へ。


3. エレベーター帰還 vs 死亡
--------------------------------------------------------------------------------
【エレベーターから拠点へ帰還】
  ・現在の RUN を終了しない（RunSeed・階マップ・踏破情報を維持）。
  ・スキルカード: 各キャラに装備中の構成を **保持**（メタ図鑑登録は行わない）。
  ・レリック: RUN 上の装備 3 枠＋バックパック分 → メタ「レリック倉庫」へ強制保管。
  ・素材: RUN 内拾得分 → メタ「素材倉庫」へ強制保管。
  ・塔片: RUN ウォレット維持。
  ・その後拠点 UI を表示（§5）。拠点ではスキルカードの入れ替えは不可（§6）。

【死亡】
  ・拠点へ強制送還。
  ・RunSeed を更新し、ダンジョンマップを再生成。
  ・踏破情報（revealed）をリセット。
  ・スキルカード: RUN 装備分を失い、**各キャラ初期スキルのみ**に戻す（新 RUN 相当）。
  ・RUN に持ち込んでいたレリック（装備・バックパック）はロスト。
  ・メタのレリック倉庫・素材倉庫・解放済みエレベーター階は維持。
  ・死亡後のエレベ再入時、その階のマップ配置・踏破は前 RUN を引き継がない（v1.0 §10–11）。


4. 塔片・カード・レリック経済（RUN 内）
--------------------------------------------------------------------------------
| 入手経路              | 塔片 | スキルカード | レリック      |
|-----------------------|------|--------------|---------------|
| Danger → 戦闘勝利     | ○    | ×            | ×             |
| Danger → 非遭遇       | ×    | ×            | ×             |
| Treasure              | ○主  | ○            | 極稀          |
| Merchant              | 消費 | ○（購入）    | ×（拠点中心） |
| Normal / Rest 等      | ×    | ×            | ×             |

  ・新規 RUN / 死亡後: 各キャラは初期スキルのみ。
  ・刻印イベント（Event）マス・戦闘後カード 3 択は廃止方向。
  ・レリック: 探索持ち込みパッシブ。死亡時 RUN 持ち込み分ロスト（§3）。


5. 拠点 UI（エレベーター帰還後・死亡後・初回）
--------------------------------------------------------------------------------
【エレベーター帰還後】
  ・必ず拠点 UI を表示。
  ・拠点で可能: レリック倉庫からの装備、店での購入、素材を使ったレリック開発。
  ・拠点で **不可**: スキルカードの装備・入れ替え・確認用デッキ編集（閲覧のみ可にするかは UI 次第）。
  ・再侵入:
      A) 1 層から（初回・死亡後など）
      B) 解放済みエレベーター階 → 同一 RUN のマップ（帰還直後の主導線）

【帰還時の倉庫ルール（確定）】
  ・帰還確定時: レリック・素材のみ CommitRunLootToMeta（1 回）。
  ・バックパックは **素材とレリック専用**。帰還後 RUN 上のバックパックは空。
  ・再入時: 倉庫からレリック装備 3 枠を選び直し、**スキルカードは帰還前の装備のまま**。
  ・帰還モーダル例:「レリックと素材を拠点倉庫に預けた。」

【死亡後】
  ・拠点 UI。1 層から or 解放済みエレベーター階から再スタート（初期スキルのみ）。


6. インベントリと装備ルール
--------------------------------------------------------------------------------
【バックパック（RUN 内）】
  ・入れられるもの: **素材・レリックのみ**。
  ・スキルカードはバックパックに **入れられない**。

【スキルカード】
  ・各キャラのスキル枠にのみ所持（装備スロット）。
  ・獲得時（宝・商人など）のみ、空き枠への自動装備 or **その場での入れ替え UI** を出す。
  ・枠が満杯で入れ替えをキャンセルした場合の扱いは TBD（見送り＝未取得が自然）。
  ・塔内の任意タイミングでの deck 編集は **行わない**（獲得時以外で入れ替え不可）。
  ・エレベーター帰還: 装備中カードは **そのまま RUN に残す**。
  ・拠点: 入れ替え **不可**。

【レリック】
  ・装備枠: 3（パッシブ）。
  ・取得時: 空き枠があれば自動装備。満杯なら **バックパック** へ。
  ・装備変更: ダンジョン内でも拠点でも可能。
  ・エレベーター帰還: 装備 3＋バックパック → レリック倉庫へ強制移動。
  ・同 RUN 再入: 拠点でレリック 3 枠を選び直してから出発。

  ・探索パッシブ（キャラ固有）とレリックは別カテゴリ（v1.0 §7–8）。


7. 踏破・マップ永続（RUN スコープ）
--------------------------------------------------------------------------------
  ・未踏マス: ?
  ・踏破後: 種類表示（Normal / 危 XX% / Treasure 等）。
  ・エレベーター帰還: マップ・踏破を同 RUN 再入でも維持。
  ・死亡: マップ再生成＋踏破リセット。
  ・恒久: 解放済みエレベーター階のみメタで維持。

  ・同一 RUN 中、同一階再訪は RunSeed + FloorNumber で同一レイアウト（v1.0 §13）。


8. データモデル（実装指針）
--------------------------------------------------------------------------------
【メタ】
  ・towerSeed、revealedTowerNodeIds（死亡でクリア・帰還で維持）
  ・unlockedElevatorFloors、素材倉庫、レリック倉庫、arcaneShards 等
  ・スキルカードはメタ倉庫に **保存しない**（RUN 装備状態のみ）

【RUN 中】
  ・塔片（RunCoins）
  ・各キャラのスキルカード装備（帰還・同 RUN 再入で維持／死亡で初期化）
  ・バックパック: 素材・レリックのみ（帰還で倉庫へ移動し RUN 側は空）
  ・レリック装備 3 枠（帰還で倉庫へ移動）

【廃止・作り替え対象（現プロト）】
  ・ExtractRun による AddSkillsToArchive / 「カードを確保」UI
  ・スキルカード用バックパック（RunPartyState.AddToInventory 等）
  ・拠点でのカード編集
  ・Combat / Elite / Event マス、宝＝塔片のみ、死亡時 seed リセット未実装 等
