# 戦闘UIブラッシュアップ案 v0.3

2026-10-29。ユーザー提供の現在の戦闘画面を編集した静止画サンプル。v0.2の機械的な別デザインへ置き換えず、現行画面の魅力を残す。

## 維持するもの

- 左の大きな立ち絵と斜めの画面分割。
- 中央の敵を囲む円と、三角形に配置した3つの入力候補。
- 下部の彫刻的な5つのオーブ受けとHP・狂気の装置。
- 赤い背景とキャラクターを中心にした劇的な雰囲気。

## Live2Dの前提

左の人物はLive2Dで少し動き、別キャラのスキル発動時にはそのキャラへ入れ替わる。今回の画像はそのうちの1状態。

UIはキャラの身体に追従させず、一定の位置へ固定する。スキルの文字の背後には濃い表示面を置き、白い衣装・暗い衣装のどちらでも読めるようにする。

実装時には全キャラの顔・髪・武器の最大可動範囲を重ね、スキル欄や入力候補と干渉しないか確認する。立ち絵の入れ替わりがあっても入力候補は動かさず、打っている位置を見失わせない。

## 主な変更の狙い

1. スキル欄：濃い背景、読みやすい文字、数値の整列。発動中の行だけを強調する。
2. 入力候補：三角配置を保ち、同じ材質・枠で揃える。入力中の候補と入力済み部分を明確にする。
3. 円：発光を抑えて、文字と敵に視線が向くようにする。
4. 下部装置：彫刻的な質感を残しながらHP・狂気の数値と残量を大きくする。
5. EX欄：5枠は保ち、空欄の反復文字を抑えてコンパクトにする。機能の変更は行わない。
6. 発動通知：2行にして省略を避ける。
7. 操作案内：右下で読む必要のあるキー表示を大きくし、確率の内訳は控えめにする。

人物・敵・スキル名・装備は基本的に提供画像を参照した仮表示。入力途中の状態などは視認性を示すためのサンプルであり、プレイ記録の再現ではない。

## ファイルと確認範囲

`01_battle_polished.png` が編集案。組み込みImageGenを使用し、プロンプトを `prompt.txt` に保存する。

AIによる画像編集のため、人物や細部は元画像と完全一致しない場合がある。実装用の完成スプライトではなく、構図と読みやすさを検討する資料。ゲームコード、Live2Dモデル、既存アセットは変更していない。

確認時の注意：生成案の発動通知は「アリス」の文言と紫髪の顔アイコンが一致していない。実装時には発動者の実データから名前と顔を同時に更新する。スキル名の末尾省略や、入力済み文字の装飾も最終仕様ではない。

この画像だけでは、切替時のちらつき、表示時間、入力の反応、解像度別の可読性は検証できない。採用する変更を絞ってゲームへ適用し、実際の戦闘で確認する必要がある。
