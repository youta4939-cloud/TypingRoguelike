# Cursor作業指示書：イベントマス（社外秘）
前提：『作業指示書_帰還と全滅.md』の作業が終わってから着手すること。混ぜない。
データ：`Docs/events_layer1.json`（このファイルと一緒に置く）を `Assets/_Project/Resources/Events/events_layer1.json` にコピーして使う。

## 現状（コードを確認済み）
- `Assets/_Project/Scripts/Run/DungeonNodeType.cs` の `Event` は「v1.2 廃止。セーブ互換のみ」になっている。
- 今回は新しい値 `EventV2` を enum の末尾に追加する。既存の `Event` は互換のため残し、触らない。
- マップ生成は `DungeonMapGenerator.cs`、マス到着の処理は `RunFlowController.cs`、マップ表示は `DungeonMapUI.cs`。

## 1. データ
- 新規 `Assets/_Project/Scripts/Data/EventDefinition.cs`：JSONをそのまま読めるクラス群（EventDefinition / EventOption / EventOutcome / EventEffect / EventCondition / EventLine）。`JsonUtility` で読めるよう配列はList、型は文字列で持つ。
- 新規 `Assets/_Project/Scripts/Run/EventDatabase.cs`：`Resources/Events/` の全JSONを起動時に読む。
- effect.type：`madness`（全員の狂気に加算、値は固定値）／`hp`（全員のHPに加算、固定値）／`coins_percent`（所持通貨の%）／`card_gain`／`card_upgrade_choose`／`card_remove_choose`／`relic_gain`／`relic_lose_random`／`battle`（通常戦闘を開始し、勝てばマップへ）／`skip_row`／`reveal_floor`／`reveal_elevator`／`reveal_treasure`。
- 固定値は1層の値。層が上がるごとに0.5倍ずつ増やす（倍率＝1＋0.5×(層−1)、10の位で丸め）。`coins_percent` には倍率をかけない。
- condition.type：`none`／`min_cards`／`min_coins`／`min_relics`／`min_hp_percent`（全員が最大HPのその%を超える）／`has_next_row`。
- 狂気・HPは0〜上限で止める。狂気が上限に達したら既存の発狂処理、HPが0なら既存の全滅処理に流す。

## 2. 抽選
- `EventV2` マスに着いたら、その層のイベントのうち条件を満たすものから1つ選ぶ。
- 1回の挑戦で一度出たイベントは出さない（`DungeonRunState` にIDリストを保存）。
- 前の挑戦で出たイベントは重みを1/3にする（`MetaProgression` に直近の挑戦分のIDリストを保存）。
- 候補が0なら通常マス扱い。

## 3. 画面の流れ
1. 背景（仮画像でよい）＋タイトル＋本文。
2. セリフ：`lines` のうち今の編成にいるキャラの行から1つランダム。いなければ出さない。
3. 選択肢：各選択肢に確率と効果を実数で表示（例「ひたる　80% 狂気 −150／20% 戦闘」）。通貨は「通貨 −150（所持金の50%）」。outcomesが空の選択肢は「マップへ戻る」と表示。
4. 選び方：選択肢の言葉をタイピング、またはクリック。
5. 結果：結果テキスト1文＋効果表示1行（例「狂気 −150」「戦闘開始」）。確定ボタンでマップへ戻り、次のマスを選ぶ。
- `card_upgrade_choose` / `card_remove_choose` はカード選択画面を出し、同じカードは選べないようにする。
- `skip_row`：次の段を飛ばし、その次の段のマスを選べる状態にする。飛ばした段のマスは踏んだ扱いにしない。

## 4. マップ生成
- `DungeonMapGenerator` で `EventV2` を全マスの約20%配置する（値は定数にして調整できるように）。

## 5. デバッグ
- エディタと開発ビルドのみ、画面右上に「イベント」ボタン。押すと全イベントの一覧が出て、選ぶとそのイベントを今すぐ開始する。
- 一覧には条件を満たさないものも出し、条件を無視して開始できるようにする（灰色表示）。
- ボタンで狂気・HP・通貨を自由に増減できる小パネルも付ける。

## 6. 確認項目
1. 10本すべてデバッグから開始でき、本文・セリフ・選択肢・結果が表示される。
2. 確率表示と実際の効果が一致する（デバッグで同じイベントを20回試す）。
3. 2層扱いにすると狂気・HPの値が1.5倍になり、通貨の%は変わらない。
4. 条件を満たさないイベントは通常の抽選で出ない。
5. 同じ挑戦中に同じイベントが二度出ない。
6. 狂気が上限に達すると発狂処理、HP0で全滅処理に流れる。
7. 研ぎ師で、強化と削除に同じカードを選べない。
8. 行列で成功すると次の段を飛ばせる。
9. 編成にいないキャラのセリフは出ない。
10. 既存セーブ（`Event` 型のマスを含む）を読み込んでもエラーにならない。
