## 1. 方針

- 選択肢は 2 つ。どちらにも得と損を混ぜ、片方が常に正解にならないようにする。損は軽め。
- 確率と効果は、選ぶ前にすべて表示する（例「60%：塔片 +10／40%：狂気 +60」）。
- 狂気の増加は損だけではない。ジャックポットの威力は狂気に比例するため、狂気が低いうちは「狂気 + 強化」が得になる。今の狂気量で答えが変わるように作る。
- 各選択肢に意見タグ（攻め／守り、既知／未知）を付ける。意見の発生と信頼の増減は既存の仕組み（第 9 節）に任せる。イベント本体の `trust` 効果は、それとは別に加算する。

### 追加・改稿時の文章方針（2026-11-13）

- 正本は `Scenario/シナリオ.md`。塔は未決の魂の滞留場所であり、受刑区ではない。亡者への加虐そのものを報酬や笑いの理由にしない。
- 怪異は、業務の手順・署名・修復・記憶・仲間との距離など、日常の具体物から始める。「怖い」「不気味」と説明する代わりに、数・順序・筆跡・音などの小さな不一致を置く。
- 本文は「目に入る物 → 規則から外れる一点 → 判断が必要になる状況」。結果文は「行動の決着 → 得失に対応する描写 → 残る違和感」。怪異の正体を毎回説明しきらない。
- 選択は報酬の大小だけで分けず、現在HP、狂気、所持塔片、残りの戦闘、信頼のどれを優先するかで答えが変わる形にする。同じ効果の組み合わせに名詞だけを差し替えて量産しない。
- 確率と実際の効果は隠さない。文章上の謎は残しても、実装のない永続ペナルティ・加入・装備喪失・将来の分岐を約束しない。戦闘結果文は勝利後に読む前提で書く。
- 名前や記憶の食い違いは手がかりとして扱い、主人公の正体、三人が知らない装置の仕組み、庁の最終目的を通常イベントで断定・説明しない。固定キャラの口調を決め打ちせず、対象者は `{target}` で扱う。

今回の追加20本は既存の条件・効果だけを使用。既存8本（巡回亡者、挑戦状、鏡、番犬、出張所、弁当、分かれ道、写真屋）はID・確率・効果・意見タグを維持して文章を改稿した。残る既存42本は今回未改稿であり、全体の文体統一と数値バランスは実機で引き続き確認する。

## 2. JSON の形

```json
{
  "id": "sleeping_brute",
  "category": "battle",
  "title": "眠る大亡者",
  "minLayer": 1, "maxLayer": 15,
  "conditions": [ { "type": "min_coins", "value": 10 } ],
  "body": "本文。{target} を含んでよい",
  "options": [
    {
      "label": "寝込みを襲う",
      "stance": "aggressive", "knowledge": "known",
      "outcomes": [
        { "chance": 100, "text": "結果の一文", "effects": [ { "type": "battle", "kind": "elite" } ] }
      ]
    }
  ]
}
```

- `category`: `battle` / `hp` / `madness` / `coins` / `layer_buff` / `warp` / `trust`
- `stance`: `aggressive` / `defensive`。`knowledge`: `known` / `unknown`
- 1 つの選択肢の `chance` の合計は 100。
- `{target}` はイベント開始時に編成から 1 人をランダムに選んだキャラ名。本文・選択肢名・結果文・`trust` の `target: "random"` はすべて同じ人を指す。

## 3. 効果

数値は 1 層基準。層で増やさない（塔片の値段が層で変わらないため）。層による伸ばし方は課題として残す。

| type | 値 | 内容 | 既存コード |
| --- | --- | --- | --- |
| `hp_percent` | ±% | 最大 HP の割合で増減 | `HealFraction` / 罠と同じ |
| `madness` | ±固定値 | 狂気を増減。0〜上限で止める | `ApplyMadnessDeltaFromEvent` |
| `coins` | ±固定値 | 塔片を増減。0 未満にしない | `Coins`（加算のみ） |
| `coins_percent` | ±% | 所持塔片の割合で増減 | なし |
| `battle` | `kind`: `normal` / `elite` | その場で戦闘 | 戦闘マスと中ボス |
| `battle_enemy_hp_percent` | ±% | 同じ結果の戦闘だけ、敵 HP 補正 | `EnemyHpFraction` |
| `battle_opening_seconds` | ±秒 | 同じ結果の戦闘だけ、敵の最初の攻撃までの秒数 | `OpeningAttackSeconds` |
| `layer_word_damage_percent` | ±% | この層の戦闘で単語ダメージ補正 | なし |
| `layer_damage_taken_percent` | ±% | この層の戦闘で被ダメージ補正 | なし |
| `layer_enemy_hp_percent` | ±% | この層の戦闘で敵 HP 補正 | なし |
| `layer_opening_seconds` | ±秒 | この層の戦闘で敵の最初の攻撃までの秒数 | なし |
| `layer_battle_coin_percent` | ±% | この層の戦闘報酬の塔片補正 | `BattleCoinFraction`（1 戦のみ） |
| `layer_rerolls` | ±回 | この層の戦闘でリロール回数を増減（最低 0） | なし |
| `layer_heal_after_battle_percent` | +% | この層の戦闘に勝つたび最大 HP の割合で回復 | 信頼パッシブの戦闘後回復 |
| `warp` | ±層 | 層を移動する（第 4 節） | なし |
| `trust` | ±値、`target`: `random` / `all` | 信頼を直接増減 | `TrustRoster.SetTrust` |
| `card_choices` | +回 | 次の刻印報酬の選択肢を増やす | `CardChoices` |
| `skill_upgrade_random` | 1 | 装備中で Lv.3 未満の刻印を 1 つランダムに +1。無ければ塔片 +15 | なし |
| `relic_gain` | 1 | レリックを 1 つ提示（既存の入手と入れ替えの流れ） | 旧出来事マス |

- 「この層」は、イベントを踏んだ層の残りのマスと 4 マス目（中ボス・ボス）まで。層が変わる、帰還する、ワープすると消える。
- 同じ種類の「この層」効果は足し算。
- `battle` を含む結果では、ほかの効果（塔片・レリックなど）は勝ったあとに入る。`battle_*` はその戦闘にだけ掛かる。
- 戦闘の通常報酬（塔片 8／強敵 15）は、`coins` とは別に入る。

## 4. ワープ

- 上へ: ボス層（5 の倍数）をまたがない。行き先は「次のボス層」で止める。今いる層がボス層なら上へは行けない（条件 `can_warp_up` を満たさない）。
- 下へ: 1 層では使えない（条件 `can_warp_down`）。
- 着いた層はリールを組むところから始める。HP と狂気はそのまま持ち越す。
- 飛ばした層のエレベーターは解放されない。飛ばした層の採点は入らない。

## 5. 条件

| type | 内容 |
| --- | --- |
| `min_coins` | 所持塔片が値以上 |
| `can_warp_up` | 上へ 1 層以上ワープできる |
| `can_warp_down` | 下へワープできる（2 層以降） |

`conditions` はすべて満たしたときだけ抽選に入る。`minLayer` / `maxLayer` は層の範囲。

## 6. 実装

- 読み込みは `EventCatalog`（`Resources/Events/events.json`）。
- 画面は `LayerPathUI.ShowStoryEvent`。選択肢の確率と効果は選ぶ前に出す。
- 戦闘・休息・店・宝箱・罠・ボスは、入った瞬間にその処理へ進む。分岐は出来事マスだけ。
- リールは、イベントの行に 70% で止まり、それ以外のマスも 40% で出来事に振り替える。3マスのうち 1 つは必ず出来事になる。イベントのピース所持数は 3。
- セリフは性格ごとの仮文。名前が決まるまでこのまま。意見を言ったキャラの信頼は、選んだ側 +2、逆側 −2。
