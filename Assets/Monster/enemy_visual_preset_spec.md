# 敵ビジュアル演出プリセット仕様 v1

TypingRoguelike / 2枚絵モンスター（`graphicMode = SpritePair`）向け。  
`EnemyVisualPresetLibrary` と戦闘プレゼンター、エディタプレビューが**同じ数字**を読むための仕様書。

| 項目 | 内容 |
|------|------|
| 対象ツール説明書 | `EnemyDefinition` 3枠ローテ + `EnemyVisualRegistration`（演出は保存のみ、ランタイム未接続） |
| 参照実装 | `/workspace/art/monster/imp_knife_v1/video_v2.py`（攻撃v2・被弾/撃破v2）。補助として同フォルダ `video.py`（v1） |
| 参照画面 | `1664 × 929` px（`/workspace/art/cutin/panel_v1/raw/battle.png`） |
| サンプルFPS | 30（実装は秒単位。フレーム数に依存しないこと） |
| 印 | **確定** = v2スクリプトから抽出した実測値。**仮** = 他プリセット用にアート側で仮置き（実装後に見た目で調整してよい） |

v1動画（拡大約2.05倍・全面白フラッシュ・UIを覆う）は**使わない**。必ず v2 を正とする。

## 1. 原則（必守）

1. **敵本体は常にすべての戦闘UIの後ろ**（ソート順 / Canvas階層 / Sorting Layer）。待機も攻撃中も同じ。
2. **斬撃・飛沫・局所フラッシュ・端の光など、UIをまたぐエフェクトは加算（または半透明）で、UI上では約 35% の強度**。v2 の `ui_att = 0.65`（残し 35%）。局所フラッシュだけ `ui_att = 0.60`（残し 40%）。
3. **フラッシュは敵付近の局所のみ**。全面白フラッシュ（v1 の white-out）は禁止。
4. **最大スケールは待機サイズの約 1.30 倍**（v2 の `K_STRIKE = 1.30`）。これ以上は大きくしない。
5. 画面端の赤い光は**細い帯（16px）だけ**。画面全体を赤くしない。
6. 土煙・残像・リムライトは敵と同じく**UIの後ろ**。
7. サンプル合成用の数値はランタイムに移植しない:
   - 半透明パネル越し `AP = 0.45`
   - ピクセル単位の UI マスク復元（`restore_ui`）
   - これらはスクリーンショットへ合成するための処理。Unity ではレイヤーで足りる。
8. 力は拡大率ではなく、**ため・速度・残像・滞空・斬撃・短い揺れ**で出す。

## 2. 単位・座標系・参照画面

### 2.1 基準高さ `Eh`

`Eh` = 待機スプライトを `displayScale` 適用後に画面へ出したときの**表示高さ（px）**。

サンプルではキャンバス 600×800、`S0 = 0.62` のため:

```
Eh_sample = 0.62 × 800 = 496 px
```

距離は「サンプル画面 px」と「`Eh` 比」の両方を書く。Unity では **`Eh` 比 × 実表示高さ** でスケールすること（敵ごとに `displayScale` が違うため、生 px を固定で使わない）。

### 2.2 アンカー

- 移動・回転・スケールの支点は **足元**（`feetPivotIdle` / `feetPivotAttack`、正規化 0〜1）。
- エディタ既定は `(0.5, 0)`（テクスチャ下端中央）。サンプル小鬼の実足元はキャンバス `(305, 743)` ≈ Unity 正規化 `(0.508, 0.071)`（下から 7% 程度上）。必ずプレビューで合わせてよい。
- 待機位置を `HOME` とする。サンプル `HOME = (995, 650)`（画面座標、足元）。

### 2.3 Y軸（重要）

サンプルは OpenCV 画像座標で **Y が下向き**。表の「上 / 下」は画面上の見た目。

- サンプル px の `y` が減る = 画面上へ。
- Unity が Y 上向き（ワールド / 一部 Canvas）なら、**垂直オフセットの符号を反転**する。
- 水平は右が正。プレイヤーは画面左。飛びかかりの着地は HOME よりわずかに左。

回転はサンプルがラジアン（数学座標、反時計回りが正）。Unity の Euler は度。表には両方を書く。

イージングの対応:

| サンプル | 式 | 目安 |
|----------|----|------|
| `ease_in(t, p)` | `t^p`（0..1 クリップ） | p=2.2〜2.4 は InQuad と InCubic の間。`AnimationCurve` 推奨 |
| `ease_out(t, p)` | `1-(1-t)^p` | p=4 は OutQuart |
| `ease_io(t)` / `ss(a,b,x)` | smoothstep `t^2*(3-2t)` | InOutSine 近似より、smoothstep をそのまま使う |

## 3. 待機（呼吸）— 確定

攻撃していないときは常にこの呼吸。攻撃の着地後も同じ周期に戻す。

| 項目 | 値 |
|------|----|
| 周期 | **1.60 s**（`sin(2π t / 1.6)`） |
| 縦スケール `sy` | `1 + 0.016 * sin(...)`（±1.6%） |
| 横スケール `sx` | `1 - 0.008 * sin(...)`（±0.8%、縦と逆相で体積を保つ） |
| 支点 | 足元。地面から伸び縮みする |
| 目の明滅 | 滑らかなノイズ。範囲おおよそ 0.55〜1.00。点滅させない |
| リムライト | 右上からの暖かい縁光。サンプル BGR `(0.35, 0.55, 1.0)×0.55` + 外側ハロー `(0.10, 0.12, 0.55)×0.35` → 縁 `#FF8C59`、ハロー `#8C1F1A`。強さは控えめでよい |

`EnemyMotionPreset.Idle` / `None` でも、SpritePair ならこの呼吸はかけてよい（`None` で完全静止にしたい場合はライブラリにフラグを分けてもよい）。

## 4. 攻撃モーションプリセット

### 4.0 共通ルール

- フェーズ名: **ため（windup） / 跳び（leap） / 滞空（hang） / 降下（dive） / 着弾（impact） / 復帰（recovery）**。使わないフェーズは長さ 0。
- スプライトは `idleIllustration`（立ち絵）と `attackIllustration`（攻撃絵）の2枚。切替タイミングは各表の「絵」列。
- 表のスケールは **待機サイズに対する倍率**（`displayScale` 適用後）。1.00 がいつもの大きさ。
- 残像・モーションブラー・土煙の有無はプリセットごとに書く。
- `EnemyMotionPreset.Lunge` だけ数値はすべて **確定**。それ以外は **仮**。

攻撃開始 `t = 0` は **ため開始**。デモ動画の先頭 1.30s の呼吸は含めない。

## 5. Telegraph（予告）との連動

攻撃枠 `EnemyAttackPattern.effect == Telegraph` のとき:

1. **ため時間 = `effectValue` 秒**（プリセット既定のため時間を上書き）。
2. ためポーズへ入る時間は、プリセットのためイージング長さ（Lunge なら 0.57 s）を上限にする。
   - `effectValue` がそれより長い: ポーズ完成後、残り時間は**構えを保持**。ゆっくりした震え（振幅 2〜3 px ≈ 0.005 Eh、周期 0.20 s 程度）と、弱い赤み（後述の被弾赤の 30〜40%）。目の光はため終了値のまま。
   - `effectValue` がそれより短い: ためイージングを `effectValue` に圧縮。下限 **0.20 s**（それより短い値でも 0.20 s は確保し、足りない分は攻撃間隔側で調整する想定。0 のときはプリセット既定に戻す）。
3. ためが終わったら、**跳び以降（Lunge なら 0.29 s で着弾 → 復帰）はプリセット通り**。
4. `effect != Telegraph` のときは、ため時間はプリセット既定（または `windupSecondsOverride`）。

既存の予告UI（タイマーや警告）がある場合は、ため演出と**同じ秒数**で動かす。プレイヤーが「見た目のため」と「実際の攻撃」を一致させて読めるようにする。

## 6. `EnemyEffectIntensity`（小・中・大）

v2 の見た目は **Medium** を 1.00 とする。

| 項目 | Small | Medium（v2） | Large |
|------|-------|----------------|-------|
| 乗数（目安） | ×0.67 | ×1.00 | ×1.44 |
| 攻撃の揺れ振幅 | 6 px | **9 px** | 13 px |
| 被弾の揺れ振幅 | 4 px | **6 px** | 8 px（v2 2撃目が 8） |
| 残像枚数 | 2 | **3** | 5 |
| 残像の不透明度 | ×0.70 | ×1.00 | ×1.15 |
| 斬撃（等）の幅 | ×0.70 | ×1.00 | ×1.35 |
| 飛沫数 | 40 | **70** | 110 |
| 局所フラッシュ peak | 0.35 | **0.55** | 0.75 |
| 端の光 | 幅 12px・弱い | **幅 16px・係数 0.30** | 幅 24px・係数 0.40 |
| ヒットストップ | 0 | **0.05 s（仮）** | 0.10 s（仮） |

ヒットストップ（着弾で時間をごく短く止める）は v2 スクリプトには無い。着弾のつぶれ 0.38 s が「間」を担っている。追加する場合は上の仮値。入れるなら敵とエフェクトだけ止め、UIタイマーは止めない方が安全。

揺れ振幅の px は参照画面 1664×929 上の値。実装では `9/929 ≈ 0.0097` 画面高さ、または `9/496 ≈ 0.018 Eh` でスケールしてもよい。ただし揺れは画面効果なので、**画面高さ比**の方が安定する。

## 7. 攻撃枠ごとの強度（新規・任意フィールド）

現状、演出強度は敵の `visual.effectIntensity` が1つだけで、枠のダメージ差（30 と 80 など）が見た目に出ない。

`EnemyAttackPattern` に任意フィールドを追加する:

```text
visualIntensity : Inherit / Small / Medium / Large
```

- `Inherit`（既定）: 敵の `visual.effectIntensity` を使う。
- それ以外: その枠だけ上書き。強攻撃枠を Large、連撃枠を Small にできる。
- 名前は既存スタイルに合わせてよい（例: `effectIntensity`, 未設定は Inherit）。
- モーションプリセット自体は敵単位のままでよい（枠ごとに Lunge / Swing を変えるのは将来で可）。

## 8. `EnemyStrikeEffectKind`（着弾エフェクト）

## 13. ダメージ同期（必守）

**与ダメージは着弾フレームで適用する。** `BattleController` のスイング完了と、プレゼンターの着弾を同じ時刻にする。

推奨フロー:

1. `BeginAttackOnSlot`（枠のタイマー発火）で `EnemyBattlePresenter` が攻撃演出を開始する。
2. Telegraph あり: ため = `effectValue` 秒（§5）。既存の予告UIもこの秒数。
3. ため終了後、アクティブ区間（Lunge なら hop 前まで = **0.29 s**）を再生する。
4. **アクティブ区間の終了 = 着弾 = ダメージ適用 = スイング完了**。斬撃・フラッシュ・揺れ・ヒットストップもここ。
5. 復帰（Lunge なら 0.38+0.40+0.50 ≈ **1.28 s**）は視覚だけ。次枠のインターバル計測は着弾から開始してよい。
6. 次の攻撃のためが、復帰が終わる前に来たら、復帰を中断して次のためへブレンドする（最悪でも 0.10 s で立ち位置・立ち絵に戻してため開始）。

やってはいけないこと:

- アニメ開始と同時にダメージを入れる。
- 復帰が終わるまでダメージを遅らせる。
- Telegraph の秒数とためポーズの秒数を別々にする。

アクティブ長の早見（着弾までの、ためを除いた時間）:

| プリセット | ため（既定） | ため終了→着弾 | 着弾までの合計 |
|------------|--------------|----------------|----------------|
| Lunge **確定** | 0.65 | **0.29** | 0.94 |
| RushForward 仮 | 0.40 | 0.16 | 0.56 |
| SwingInPlace 仮 | 0.45 | 0.16 | 0.61 |
| CastMagic 仮 | 0.80+0.20 | 0.08 | 1.08 |
| Idle 仮 | 0.20 | 0.15 | 0.35 |
| None 仮 | 0 | 0（即エフェクト） | 0 |

## 14. パラメータの解決順

`EnemyVisualRegistration` の `*Override` は **0 ならライブラリ既定、0 より大きければ上書き**（説明書のどおり）。

推奨する解決順（後の方が優先）:

1. `EnemyVisualPresetLibrary` のプリセット既定（この仕様の表）
2. 敵の `visual.motionPreset` / `strikeEffect` / `effectPalette` / `effectIntensity` / `defeatPreset` / `hitFlashColor`
3. 敵の `windupSecondsOverride` など `*Override`（0 は無視）
4. 攻撃枠の Telegraph `effectValue`（ため時間のみ）
5. 攻撃枠の `visualIntensity`（Inherit 以外）

説明書に明示されているのは `windupSecondsOverride` 等。ライブラリ実装時、次があればそのまま使い、無ければ追加してよい（すべて 0 = 既定）:

- `windupSecondsOverride`
- `maxScaleOverride`（上限はなお 1.30 を推奨。超える場合も 1.30 でクランプしてログ）
- `leapHeightEhOverride`（Lunge の頂点の高さ、Eh 比）

## 15. アセット規則とエディタ警告

### 15.1 素材ルール（トダさん／登録者向け）

- **立ち絵と攻撃絵は同じキャンバスサイズ**の透明 PNG。
- 背景は完全透明。白やグレーの下地を残さない。
- 足元の位置を揃える（同じ地面線）。ピボットはプレビューでクリックして合わせる。
- 推奨キャンバスはサンプルと同じ **600×800**（強制ではないが、揃えると倍率管理が楽）。
- 余白は足元側に少し残してよい。顔や武器を端で切らない。
- 命名はプロジェクト既定に従う（例: `enemyId_idle.png` / `enemyId_attack.png`）。

### 15.2 エディタで出してほしい警告

`SpritePair` のとき、保存またはプレビュー時に:

1. 立ち絵と攻撃絵の **テクスチャ解像度が違う**。
2. **アルファが無い**（不透明インポート、またはほぼ全画素 α=1）。背景が塗り潰されている可能性。
3. `SpritePair` なのに攻撃絵が未設定。
4. （任意）ピボットが初期値のまま、かつ足元が画像下端から大きく離れている。

警告は登録をブロックしなくてよい。量産時に気づければよい。

## 17. 実装メモ

  - `SpritePair` だけが本仕様のプレゼンターを使う。
