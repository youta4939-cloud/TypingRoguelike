# hand_parts_v2 — 手札カード（発動条件をカード上辺へ移動）

v1 からの変更は **配置だけ** です。パーツ PNG は hand_parts_v1 と同じものをコピーしています（`parts/`）。
カードは 313×150、座標はカード左上 (0,0) 基準、1920×1080 での 1x です。

## 変更点
| 要素 | v1 | v2 |
|---|---|---|
| 発動条件（宝石＋楕円の下地） | 名前の下（下地 x18, y50, h32） | **上辺をまたいで右揃え**：下地の右端 x=265、y=-16〜16（上端 y=0 が中心）。宝石は y=-12〜12 |
| 状態タグ（条件成立／あと1色／チェーン） | カード中央の上 | **左上**：スプライト左上 (-2,-54) → タグ本体 x=8〜、y=-44〜-16 |
| 名前 | ベースライン y40 | y48 |
| 区切り線 | y90 | y64（x20〜190） |
| 効果テキスト | ベースライン y114 / 141 | y102 / 132（行間を広げた） |
| ×N バッジ・★・光彩・重なりカード | — | 変更なし（バッジ (W-42,-22)、本体 x277〜328） |

### 宝石の x 座標（右揃え。どのカードでも右端の列がそろう）
| 色数 n | 下地 x | 1個目の宝石 x | 間隔 |
|---|---|---|---|
| 1 | 227 | 234 | 28 |
| 2 | 199 | 206 | 28 |
| 3 | 171 | 178 | 28 |
| 4 | 143 | 150 | 28 |
| 5 | 115 | 122 | 28 |

下地の幅 = n×24 + (n−1)×4 + 14。宝石の ON／暗（明るさだけ 42%）は v1 と同じです。

## すき間の確認（1x）
- 宝石の下地の右端 265 と ×N バッジ 277 の間は 12px あります。
- 状態タグ（最大幅「あと1色＋色」は x8〜126、高さ y-44〜-16）は宝石の下地（y-16〜）より上なので、5色でも重なりません。
- 名前の上端（約 y22）は下地の下端 y16 より下です。

## 描画順（Unity の Hierarchy 下から）
1. 状態の光彩 (-28,-28)
2. 重なりカード (6,-6)
3. カード本体（ベース → 絵 → グラデ → 枠 → 色の縁 → 名前・線・効果・★）
4. あと1色の上辺ハイライト
5. **宝石の下地 → 宝石**（枠より上に描きます。上辺をまたぐため）
6. ×N バッジ
7. 状態タグ

持ち上げ量は v1 と同じです（あと1色 +14、条件成立 +28）。
