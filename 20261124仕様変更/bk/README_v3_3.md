# Cursor用パック v3.3（戦闘画面：ガイド＋手札）
※社外秘

v6-C（cursor_pack_v6C）からの変更点をまとめたパックです。完成形は reference/mock_v3_3.png です。

## 1. ガイドチップ（単語カードの下）
- 頭に種類アイコン（icons/、ガイド上は24px）
  - attack → icon_attack
  - shield → icon_defense
  - buff → icon_buff
  - heal（回復系consumable）→ icon_heal
  - debuff → icon_debuff
- 文言の形は「効果（スキル名）」＋状態（発動／あとN）。例：6ダメージ（斬撃） 発動、シールド5（防御） あと1
  - 発動は金の文字、あとNは灰色の文字
- チップの枠はすべて同じ灰色で1px（次の色で着色しない、光も付けない）
- チップの幅は単語カードと同じ250pxで固定し、左端も単語カードにそろえる。長い文は折り返す
  - 本文はチップ左端から51px、右余白8px、本文幅191px
  - 行の高さは1行目26px、2行目以降は1行ごとに+22px。チップ同士の間は4px
  - 改行は（スキル名）の前、次に全角＋の前。単語の途中では切らない
  - 発動／あとNは1行目の右端。入らなければ最終行の末尾
  - 1単語あたり合計3行まで。超えた分は右揃えの「+n」
  - 詳細は layout_guide_icons_v3_2.json の wrap
- 進むカードが無い単語の下には何も出さない（「進むカードなし」は廃止）

## 2. 右側パネル
- 「前の色」パネルは廃止
- STOCKパネルのみを、単語カードの高さの中央に置く（y622〜674）

## 3. 手札カード（画面最下部・1.2倍）
- 両端の色バー（parts/edge）は使わない。このパックからも除外済み
- 発動条件のジェム土台は上辺をまたいだまま、カードの左右中央に置く
  - 1倍・幅313pxで、土台の幅は28n+10、左端は(313−幅)//2
  - 詳細は layout_guide_icons_v3_3.json の hand_cards
- 持ち上がったカードの「あと1色」タグは出さない

その他（持ち上がり17/34px、光、文字、星、配置）は v6-C と同じです。基準の配置は layout_v6.json の mocks.C を参照してください。
