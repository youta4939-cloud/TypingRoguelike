# Cursor指示書：デッキ構築 試作2（バグ修正＋手札UIを彩木さんのパーツで作り直し）

作業ブランチ：`feature/deckbuild`。試作1の仕組み（山札・手札5枚・捨て札・重なり・消費カード・シールド）はそのまま使い、下の問題を直す。
数字はすべて仮。

## A. バグ修正（最優先）

### A1. カードが消える
- 初期デッキが10枚なのに、手札が「防御×3、斬撃×3、居合い斬り」の7枚分しかなく、山札も捨て札も0だった。3枚がどこにも無い。
- 原因を調べて直す。重なりが3枚で止まったとき、4枚目以降を捨てている可能性が高い。
- **枚数の保存チェックを入れる**：カードを動かすたびに「山札＋手札（重なり枚数込み）＋捨て札＋消滅した枚数＝戦闘開始時の枚数（＋戦闘中に加えた消費カード）」を確認し、合わなければ `Debug.LogError` を出す。
- 同名カードの重なりは最大3枚（Lv3）まで。**4枚目が手札に来たら、別の1枚として手札に置く**（重ねない）。ただし、初期デッキは同名2枚までにするので、通常は起きない。

### A2. 初期デッキを入れ替え
`Resources/Deck/cards.csv` と `starter_deck.csv` を、末尾の付録の内容に差し替える（12枚・7種、同名は2枚まで）。
これで手札5枚に全部が入らず、山札が回る。

### A3. デッキモードで古い表示を隠す
- 敵の名前の下にある開発用の行（敵HP、ATK、単語ダメ、会心率など）と、「会心テスト」「テスト：アリスATK30%」のボタンは、デッキモードでは隠す（消さない）。
- ATKやパーティの数字を使う表示は、デッキモードでは出さない。

## B. 手札UI（彩木さんのパーツ）
パーツは `hand_parts_v2.zip`（添付）を `Assets/_Project/Resources/UI/HandParts/` に展開して使う。
**座標・重ね順・色・フォントは、同梱の `README.md` と `layout.json` が正**。この指示書と違うところがあれば、そちらに合わせる。
見た目の完成形は `mock_B2b_v4.png`（添付）。1920×1080 基準、原点は左上。

### B1. カード1枚（313×150）
重ね順（下から）：
1. 状態の光（カード位置から -28,-28）
2. 重なりの「後ろのカード」（+6,-6。重なりがあるときだけ）
3. 下地 → 技の絵（マスク）→ 文字用グラデ → レア枠（N銀/R金/SR虹）→ 左右の色の帯（左＝最初の色、右＝最後の色）→ 名前・区切り線・効果文・★
4. あと1色の上辺ハイライト
5. 発動条件の宝石の下地 → 宝石（**カードの上辺をまたいで右揃え**。座標は `layout.json` の `gem_backing.x_for_n` と `gems.x_first_for_n`）
6. ×2／×3 の重なりバッジ（右上）
7. 状態タグ（左上。「条件成立」「あと1色＋色」「チェーン」）

- 名前：Shippori Mincho ExtraBold 28px、効果文：Noto Sans JP Bold 20px、2行まで。**文字が切れないように**、最大幅を超えるときは自動で縮小する（TMPの Auto Size、最小16px）。
- 宝石は、オーブ列と一致した色を `on`、まだの色を `dim` にする。
- ★は重なりLv（1〜3）。
- 技の絵は仮で `placeholder_slash`（赤系の技）と `placeholder_moon`（それ以外）を使う。

### B2. 手札の並びと状態
- 5枚の位置と持ち上げ量は `layout.json` の `hand_positions` と `lift` に従う（通常 y916、あと1色 +14、条件成立 +28）。
- 状態の判定：
  - **条件成立**：オーブ列の末尾がそのカードの色の並びと一致している（発動直前の状態）。金の光と「条件成立」タグ。
  - **あと1色**：あと1色で一致する。淡い光と「あと1色」タグ（足りない色の宝石つき）。
  - **チェーン**：カードの最初の色が、直前に発動したカードの最後の色と同じ。白い光を直前の色で着色し、「チェーン」タグ。持ち上げはしない。
- 空き枠（山札も捨て札も0で補充できないとき）は、薄い枠だけ表示する。

### B3. 手札まわりの表示（モックv4の左下）
- 左下に小さい顔アイコン、その横にHPとSANのバー（SAN＝今の狂気の表示を使う）。
- その下に「山札 n」「捨て札 n」の数字。
- **シールド**：HPバーの横に盾アイコンと数字（0のときは隠す）。敵の攻撃を受けて消えるときに割れる演出（今の `ShieldCrack` の音を流用してよい）。
- 単語の下に「前の色」（直前に発動したカードの最後の色）と「STOCK」（今のオーブ列）を表示。

### B4. 大きい立ち絵は出さない
- モックv4と同じく、デッキモードでは左側の大きい立ち絵を出さない（コードは消さない）。
- キャラは左下の小さい顔アイコンだけで表示する。

## C. 確認方法
1. 戦闘を開始して、手札5枚が彩木さんのモックv4と同じ見た目で並ぶ。山札の数が7（12−5）になる。
2. 同名カード2枚が手札に来ると、1枠に重なって「×2」と★2つになり、空いた枠が補充される。
3. カードを使うたびに、Consoleに枚数チェックのエラーが出ない。何戦しても、山札＋手札＋捨て札が12枚のまま。
4. オーブ列に応じて、宝石の on／dim と「あと1色」「条件成立」の表示が切り替わる。
5. 防御を使うと盾の数字が出て、敵の攻撃1回で消える。
6. 効果文が2行に収まり、切れない。
7. 開発用の行とテストボタンが出ない。
