# Cursor指示書：デッキ構築 試作1（1人＋デッキ＋手札5枚）

作業ブランチ：`feature/deckbuild`（`backup/3party-2026-11-23` は触らない）
Unity 6000.3.25f1。数字はすべて仮。あとでCSVだけで差し替えられるようにすること。

## 目的
3人パーティ・9スキル固定の戦闘を、「キャラ1人＋デッキ（山札・手札5枚・捨て札）」に置き換えて、まず遊べる形にする。
既存の文字入力（TypingEngine）、オーブ（OrbStock の末尾一致）、Exエリア、敵の攻撃タイマー、マップ、イベント、狂気（RunMadnessState）はそのまま使う。

## 1. カードデータ（CSV）
- `Assets/_Project/Resources/Deck/cards.csv` を読み込む（UTF-8、1行目ヘッダ）。
- 列：`id,name,colors,type,value,consumable,addCardId,rarity,text`
  - `colors`：色の並び。`R/B/G/Y/P`（赤/青/緑/黄/紫）を `-` でつなぐ（例 `R-R-B`）
  - `type`：`attack`（固定ダメージ）/ `shield`（シールド）/ `buff`（次の攻撃カードのダメージ+value、試作は単純加算でよい）
  - `value`：数値（ダメージ量、シールド量など）
  - `consumable`：`1` なら使うと消滅（捨て札に行かない）
  - `addCardId`：使ったときに手札へ加える消費カードのid（空なら無し）。**加えるのは1枚まで**
- 初期デッキも `Assets/_Project/Resources/Deck/starter_deck.csv`（`cardId,count`）で読む。
- 仮データは末尾の付録の内容でファイルを作る。

## 2. 戦闘中のデッキ処理
- 戦闘開始時：初期デッキ（ラン中に増えたカード含む）をシャッフルして山札にし、5枚引く。
- **手札の重なり**：手札に同じidのカードが2枚以上あると自動で1枚に重なり、その戦闘中だけレベルが上がる（2枚=Lv2、3枚=Lv3。デッキ内の同名は最大3枚）。
  - 重なったカードは手札1枠として数え、空いた枠はすぐ山札から補充する（補充したカードがまた重なれば、さらに補充）。
  - レベルごとの効果：仮で value × (1, 1.5, 2.0)。係数は定数1か所にまとめる。
  - 使ったら、重なっていた枚数すべてが捨て札へ行く。
- **発動**：今の `SkillResolver.ResolveTriggeredSkills` と同じく、オーブ列の末尾が手札カードの `colors` と一致したら発動。**条件を満たした手札カードはすべて発動**する。
  - 同時に発動するときの順番：①buff → ②shield → ③attack → ④消費カードの追加。同じ種類の中では手札の左から順。
  - 対象は**手札のカードだけ**（山札・捨て札のカードは発動しない）。
  - 今の「同じスキルの連続発動を止めるクールダウン」は、カードが手札から出ていくので不要。デッキモードでは無効にする。
- **処理順（1枚ごと）**：①スキル発動 → ②手札から出す（通常は捨て札へ、消費カードは消滅）→ ③効果処理（消費カードの追加は1枚まで）→ ④手札が5枚**未満**なら5枚まで補充。
- 山札が0枚で引く必要があるときは、捨て札をシャッフルして山札に戻してから引く。山札・捨て札とも0なら引かない。
- 演出：ロジックは即時に処理し、演出（0.3〜0.5秒）は見た目だけ後から追いかける。演出中に単語を打ち終えても、**その時点の手札**で発動判定する。入力や敵タイマーは止めない。

## 3. ダメージとシールド（ステータス廃止）
- ATK・DEF・LUCK・信頼値によるダメージ計算はデッキモードでは使わない（割合ダメージ・防御による軽減をしない）。
- attackカード：value の固定ダメージ（＋buff分、×重なりレベル係数）。
- 単語ダメージ：`ローマ字の文字数 × 1`（係数は定数1か所、仮で1）。
- **シールド**：shieldカードの value を加算して1つのシールドにまとめる。
  - 敵の攻撃を1回受けたら、量に関係なく消える。
  - 攻撃 ≦ シールドならダメージ0。攻撃 ＞ シールドなら差分だけHPから引く。
  - 画面に今のシールド値を表示（仮UIでよい）。
- HP回復カードは試作では作らない。

## 4. キャラ1人化
- 戦闘に出るのは選んだキャラ1人（試作は剣士固定でよい）。
- 9枠のパーティUI（BattlePartyCardUI 等）は、デッキモードでは非表示にする。消さずに残す。
- 信頼値・意見システムは、デッキモードでは呼ばない（表示も隠す）。コードは消さない。
- 切り替えは、設定1か所（例：`GameModeConfig.UseDeckMode = true`）でできるようにする。

## 5. 仮UI（見た目は後で彩木さんのパーツに差し替え）
- 画面下に手札5枠を横並び。各カードに名前、色の並び（色の丸）、効果の数字、重なりLvを表示。
- 今のオーブ列の末尾と一致しかけているカード（あと1色で発動）を少し光らせる。
- 山札の枚数・捨て札の枚数を数字で表示。

## 6. 今回やらないこと（2本目以降）
- 戦闘後の報酬（3つから1つ）、ショップのカード購入・削除、レアリティの出現率。
- エレベーター間隔の変更、層数の変更。

## 7. 確認方法
- 剣士で戦闘を始めて、手札が5枚表示される。
- 斬撃（赤赤）が2枚手札に来たら1枚に重なってLv2表示になり、空いた枠が補充される。
- 赤赤を打つと斬撃が発動して捨て札へ行き、手札が5枚に戻る。
- 防御（緑緑）でシールドが付き、敵の攻撃1回で消える。攻撃がシールド以下ならHPが減らない。
- 山札が尽きたら捨て札が混ざって山札に戻る。
- `UseDeckMode = false` にすると今までの3人パーティ戦闘に戻る。
