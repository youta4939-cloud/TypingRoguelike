# D2-M カードフレーム 重ね合わせキット（v2：レベルは文字表記）

ご自身で生成したカードイラスト（文字・ジェムなし）に重ねる透過PNGパーツ一式です。
レベル・カード名・効果テキストはプログラムで描画し、ジェムとカプセル（背板）もプログラムで配置します。
文字の仕様（Unity TextMeshPro での再現方法を含む）は **`typography_spec.md`** にあります。

| フォルダ | 内容 |
|---|---|
| `1x/` | 750×1050 |
| `2x/` | 1500×2100。全パラメータを2倍にして描き直したもの（拡大ではありません） |
| `compare/` | 比較シート（レベル表記・ジェムのカプセル・効果テキストの書体・名前の色・長い名前） |
| `reference_stars/` | （参考）旧案の星3つ表示。プレート幅250、ジェム44px |
| `licenses/` | フォントのライセンス（OFL 1.1）全文 |

- 全画面サイズのレイヤーはすべて同じキャンバスサイズで、**(0,0) に重ねるだけ**で位置が合います。
- 座標・サイズ・色は各フォルダの `layout.json` にあります（そのフォルダの解像度の px）。

## 重ね順（下から上へ）

1. **art**：ご自身のイラスト
2. **card_mask.png** でアートを切り抜く（グレースケールのマスク。白＝表示）
3. **shade_bottom.png**：文字の下を暗くするグラデーション（y 660〜、y 880 以降は不透明度 244/255）
4. **shade_top.png**：レベルプレートの暗い地の板と、その周りの柔らかい影
5. **frame_{silver|gold|rainbow}.png**：含まれるもの
   - 13px の金属の帯と内側の細線
   - レベルプレートの金属の縁
   - 名前の下の区切り線
   - レア度別の装飾（silver：帯のみ／gold：四隅の装飾／rainbow：四隅＋上下中央の紋章＋左右のガーネット＋控えめな光沢）
   - 帯と装飾の内側の影
6. **レベル文字**（プログラム）：プレート (275,26)〜(475,76) の中央。描画した見本は `preview/level_{lv1,lv2,lvmax,lv2of3}.png`
7. **カード名・効果テキスト**（プログラム）
8. **ジェムのカプセル**（プログラム）：`pieces/capsule_{rarity}_n{1-4}.png` から、ジェムの個数に合うものを使います
9. **ジェム**（プログラム）：`gems/gem_{R,Y,G,B,P}_{on,dim3}.png`（1x は 60px、2x は 120px）

## 主な数値（1x）

- **レベル**：Cinzel Bold
  - サイズ：「Lv」24px、数字 38px、「MAX」31px、「/3」24px
  - 色：通常 #ECE8F4
  - MAX：縦グラデーション（上 #FFF6C8 → 下 #E8A434）＋淡いグロー
- **カード名**：Shippori Mincho ExtraBold 84px（自動縮小で最小 52px）
  - 位置：x=50、ベースライン y=860
  - 色：アイボリー #FCF6EE、またはレア度で色味を付ける案
  - 名前は6文字までを推奨
- **効果テキスト**：Noto Sans JP Bold 40px
  - 位置：1行目の上端 y=902、行の高さ 52px、最大2行、幅 650px
  - 色：本文 #F0ECF6、数値 #F2D58A
- **ジェム**：60px、間隔 8px、中心 y=830、右揃え
  - カプセル：高さ 76px、余白 8px、右端 x=700
  - 名前の最大幅（ジェムの個数別）

    | ジェムの数 | 名前の最大幅 |
    |---|---|
    | 1個 | 558 |
    | 2個 | 490 |
    | 3個 | 422 |
    | 4個 | 354 |

- **イラストの安全領域**：顔は x 110〜640、y 100〜640 の範囲内（理想は中心 (380,380) 付近）
  - 上部中央はプレート、y 660 より下は文字、右下はカプセルの位置です。
  - 四隅 56px は装飾が入ります。

## 再生成

- `python3 build_kit.py`（1x と 2x）
- `python3 make_compare.py`（比較シート）
- `python3 make_overview.py`（一覧画像）
- `typo.py`：文字描画の見本。TMP で再現できる効果だけを使っています。
