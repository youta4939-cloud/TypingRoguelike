# Chara01 絵柄検討

方式: built-in image_gen。4種とも同じ元キャラクターを参照して生成。ゲーム本体には未反映。

## 共通プロンプト

Create ONE original Japanese game recommendation sticker with REAL TRANSPARENT BACKGROUND alpha, no opaque backing, no checkerboard texture, no UI or screenshot. Input image is character identity reference ONLY, radically redesign drawing style as directed, DO NOT copy polished anime rendering. Recognizable anchors: black hair, side-swept bangs, white headband with oval silver detail, red eyes, extremely long black rear ponytail/locks, oversized cropped white hoodie with black drawstrings and red lining, simplified black undersuit. Make completely nonsexual tiny cartoon proportions. One character only. Readable exact Japanese text「絶対こっち！」, playful lettering integrated alongside character, no other words or style labels. Transparent margin around whole silhouette, nothing clipped. Bold clean outline, white die-cut keyline around text and character for dark-background legibility. Compact composition suited to displaying below a game option. Avoid generic standard anime chibi: this is a distinctive stylized illustration experiment.
